# Логово волков из Tripo

Груда серых валунов с тёмным устьем, мох сверху, потёки крови на камнях по бокам устья, кости у входа.

## Посадка вместо старого логова (из обратного импорта обоих FBX, оси Blender)
| | старое | новое |
| --- | --- | --- |
| Границы по X | −2.161 … 2.170 | −2.161 … 2.170 |
| Границы по Y | −1.495 … 1.573 | −1.495 … 1.573 |
| Высота | 3.617 | 2.556 |
| Точка опоры | (0, 0, 0), низ Z = 0 | (0, 0, 0), низ Z = 0 |
| Сторона входа | −Y | −Y |

- Модель Tripo повёрнута входом на −Y и растянута на пятно старого логова неравномерно: по X в 1.858 раза,
  по Y в 1.376, по Z в 2.130. Высота выбрана по входу: проём высотой 1.15 м и шириной около 1 м
  (волк с ушами — 1.06 м). Поэтому новое логово на 1.06 м ниже старого.
- Сторона входа нового: луч на высоте 0.5 м в створе устья с −Y уходит внутрь до y = 0.28, а рядом с устьем
  упирается в камни на y = −0.48 и −0.70; с +Y тот же луч останавливается на задней стенке y = 1.50.
  Сторона входа старого — по его скрипту сборки и по кадру со стороны −Y (перед его устьем лежит валун,
  лучом это не меряется).
- По правилу контракта импорт в UE зеркалит ось Y: в UE вход обоих логов смотрит в +Y.

## Что сделано с моделью Tripo
- Рваный лоскут земли перед входом и ещё 8 плоских обрывков по низу убраны (39 треугольников).
- Вместо них одна ровная площадка на высоте 2 см: пол пещеры и земля под костями у входа; под валунами она
  спрятана внутрь их контура. Нижние края валунов опущены на Z = 0.
- Снизу модель открыта (под землёй), сбоку и сверху сквозных дыр нет: из 231 луча, пущенного в устье спереди,
  ни один не проходит насквозь.
- Кости и мелкие камешки Tripo оставлены (7 отдельных деталей), поставлены на площадку.
- Затенение плоское, один материал.

## Раскраска
Цвет Tripo перепечён на новую развёртку и приведён к образцу по зонам: камень — нейтральный серый
(в среднем 0.36, 0.36, 0.34 вместо жёлто-бежевого 0.34, 0.31, 0.26), мох — тусклый зелёный (0.23, 0.25, 0.15),
кровь — тёмно-красная (0.26, 0.10, 0.08), кости — светлые (0.69, 0.59, 0.45). Нутро пещеры чёрное,
площадка — утоптанная земля с пятнами крови у входа, уходящая в черноту внутрь.

## Маска
Каналы не пересекаются, значения только 0 и 1: красный — камень (52.8% закрашенной площади), зелёный — мох (16.9%),
синий — кровь (2.0%), альфа — кости (2.4%). Нули: чёрное нутро и земля площадки. Пятна крови на земле у входа
отнесены к синему каналу, чтобы насыщенность крови настраивалась вся разом.
Листы: renders/qc_mask_on_wolfden_mouth_side.png, qc_mask_on_wolfden_game_camera.png, qc_mask_overlay_uv.png
(красный — камень, зелёный — мох, синий — кровь, жёлтый — кости).
