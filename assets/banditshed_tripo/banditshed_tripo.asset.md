# Сарай бандитов

## Почему не из сетки Tripo
У обоих заказов Tripo стены порваны: у banditshed2 целая только передняя стена, у торцов и задней стены
не хватает половин (кадры осмотра были в _work/_look), крыша мятая; текстура блёклая. При пределе 500
треугольников чинить это дороже, чем собрать заново. Поэтому форма построена начисто по образцу ref.png,
а раскраска нарисована по правилам (как у избы). От Tripo и образца взята компоновка переднего фасада:
дверь, тряпка над ней, метка, заколоченное окно справа, жестяная заплата внизу справа.

## Что в форме (130 треугольников)
- Дощатая коробка с фронтонами, дно закрыто; тёмный дверной проём глубиной 0.75 м.
- Полуоткрытая дощатая дверь (27 градусов наружу), ступенька из досок.
- Красная тряпка над дверью (провисающая лента и два свисающих конца).
- Три доски поперёк окна, две жестяные заплаты (на левом торце и внизу спереди) — плоские накладки без торцов.
- Крыша: тёмная обрешётка и 16 мест под листы — по 4 в два ряда на каждом скате; каждый лист — одна плоская
  грань, волны шифера и жести нарисованы в текстуре (6 волн на целый лист).
  На переднем скате один лист съехал и повёрнут, один треснул пополам (половины разошлись), один заменён
  ржавой жестью (справа вверху, как на образце); на заднем скате один лист съехал. Конёк — две доски.
- Красная тряпка на крыше (18 треугольников): полотнище шириной около метра перекинуто через конёк над третьим
  рядом листов (X от 0.1 до 1.2), длинный конец с рваным краем лежит на переднем скате, короткий — на заднем.
  Цвет тот же, что у тряпки над дверью.
В раскраске: доски стен со щелями, прибитые доски-заплаты, рама окна и тёмный проём, коробка двери,
красная метка краской справа от двери, поперечины двери, трещины и лишайник на шифере.

## Посадка вместо старого сарая (из обратного импорта обоих FBX, оси Blender)
| | старый | новый |
| --- | --- | --- |
| Границы по X | ±2.550 | ±2.550 |
| Границы по Y | ±1.983 | ±1.983 |
| Высота | 3.550 (труба) | 3.315 (тряпка на коньке) |
| Точка опоры | (0, 0, 0), низ Z = 0 | (0, 0, 0), низ Z = 0 |
| Дверь | −Y, по центру | −Y, по центру |
| Конёк | вдоль X | вдоль X |
| Стены | X ±2.43, Y ±1.78 | X ±2.42, Y ±1.50 |

- Дверь на −Y у обоих: в проёме луч с −Y уходит глубже стены (у нового до y = −0.75 при стене на −1.50,
  у старого до −1.67 при стене на −1.78), с +Y упирается в глухую стену.
- Стены нового сарая по глубине уже на 28 см с каждой стороны: так открытая дверь и ступенька остаются
  внутри прежнего пятна. Пятно по крыше совпадает точно.
- Дно закрыто: 299 лучей из 299 снизу встречают грань на Z = 0.
- По правилу контракта импорт в UE зеркалит ось Y: в UE дверь обоих сараев смотрит в +Y.

## Маска
Значения только 0 и 1, каналы не пересекаются: красный — дерево стен, фронтонов, двери, ступеньки, досок на
окне и конька (49.5% закрашенной площади); зелёный — шифер (31.7%); синий — ржавая жесть: лист на крыше и
две заплаты (3.9%); альфа — тряпка над дверью, тряпка на крыше и метка (3.8%, из них тряпка на крыше 3.0%). Нули: тёмный дверной проём, окно под досками,
обрешётка под шифером, низ свесов, дно.
Листы: renders/qc_mask_on_banditshed_door_side.png, qc_mask_on_banditshed_game_camera.png, qc_mask_overlay_uv.png
(красный — дерево, зелёный — шифер, синий — жесть, жёлтый — тряпка и метка).

## Заметки для UE
- Листы шифера, обе тряпки, доски на окне и жестяные заплаты — односторонние поверхности без изнанки
  (экономия треугольников): сверху и спереди они закрыты, с изнанки не видны.
- Старый материал сарая брал цвет из вершин; новому нужен материал с текстурой и маской.
