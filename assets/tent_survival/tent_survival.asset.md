# Палатка-навес из брезента

## Что в исходнике (замер, `_work/_inspect.log`)
Семь отдельных предметов, всего 172 треугольника: два полотнища брезента по 36 (толстые плиты с лишними
поясами граней) и пять шестигранных жердей по 20 (четыре перекрещенные ноги и коньковая жердь). Цвета заданы
материалами, текстур и раскраски по вершинам нет. Картинка `textures/internal_ground_ao_texture.jpeg` — тень
на земле для показа на сайте, к модели не относится и не использована. Размер исходника 7.65 x 8.54 x 5.55
условных единиц.

## Что сделано (60 треугольников)
- Форма собрана заново по замерам исходника: оси и толщина каждой жерди, углы каждого полотнища взяты из его FBX.
- Жерди — квадратные в сечении (у исходника шестигранные), стороной 7 см у ног и 9 см у коньковой; у ног нет
  нижнего торца (стоит на земле). 5 жердей = 52 треугольника.
- Каждое полотнище — одна грань снаружи и одна грань изнанки (8 треугольников на оба). Изнанка сделана своими
  гранями, потому что Unreal не рисует обратную сторону, а при низком взгляде у края кадра она видна через
  открытые торцы (кадр renders/qc_game_edge_low.png).
- Складки, выгоревший верх, грязный подол, потёртости, шов и три заплаты — в раскраске.
- Единый предмет, один материал.

## Посадка вместо старой палатки (из обратного импорта обоих FBX, оси Blender)
| | старая | новая |
| --- | --- | --- |
| Границы по X | −0.760 … 0.800 | ±0.760 |
| Границы по Y | ±1.434 (с растяжками; сам домик ±1.0) | ±0.830 |
| Высота | 1.223 | 1.081 |
| Точка опоры | (0, 0, 0), низ Z = 0 | (0, 0, 0), низ Z = 0 |
| Длинная сторона, конёк | вдоль Y | вдоль Y |
| Вход | +Y | открыта с обоих торцов: +Y и −Y |

- Масштаб один по всем осям (0.19864 от исходника): ширина подогнана под самую узкую половину старого пятна
  (0.76 м), пропорции исходника сохранены. Поэтому новая палатка короче старой: 1.66 м против 2.0 м у домика.
- По правилу контракта импорт в UE зеркалит ось Y; новая палатка симметрична, вход есть с обеих сторон.

## Маска
Значения только 0 и 1, каналы не пересекаются: красный — брезент с обеих сторон (72.7% закрашенной площади),
зелёный — дерево жердей и их торцы (27.3%), синий и альфа — нули по всему файлу. Файл четырёхканальный,
альфа равна нулю везде: при импорте в UE не включать sRGB.
Листы: renders/qc_mask_on_tent_game_camera.png, qc_mask_on_tent_entrance_side.png (красный — брезент, зелёный — дерево).

## Заметки для UE
- Все 60 граней смотрят лицом к зрителю (`NEW facing TOTAL wrong 0 of 60`), двусторонний материал не нужен.
- Старый материал палатки брал цвет из вершин; новой нужен материал с текстурой и маской.
- Между брезентом и ногами зазор около 2.5 см (толщина плиты исходника) — виден только вплотную с торца.
