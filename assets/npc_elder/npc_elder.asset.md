## Что это
Деревенский старейшина, **комплект «Б»** («жилет + вязаная шапка») по утверждённому Ринатом
референсу `concept-art/ElderRefecrence/1.png` и промптам `docs/contrary-survivor/art/npc-elder-trader-prompts.md` §2.
Три **модульных скинённых меша** под слоты Head/Torso/Legs на **общем скелете** (ADR-018) — это
НЕ класс; актор `BP_Elder` (AElderNPC → AMasterHumanoidCharacter, ADR-026) надевает их в 3 слота.

- **Head:** голова + короткие седые волосы + густая седая борода + коричневая вязаная шапка (низкий округлый купол, без козырька).
- **Torso:** бежевая рубаха с рукавами, закатанными до локтя (предплечья голые) + коричневый жилет-безрукавка (V-вырез, 3 пуговицы) + воротник.
- **Legs:** тёмно-серые прямые штаны + коричневые ботинки + тёмный ремень с пряжкой.

## Скелет / привязка (пруф — `_export_elder.log`, ROUNDTRIP ALL PASS)
- **Общий скелет `RootAnim`, 21 кость**, имена 1-в-1 с хендофф-скелетом (`_handoff/humanoid-export/SK_Cloth_L1_Torso.fbx`),
  из которого собран UE-скелет `/Game/Characters/Shared/Humanoid/HeadAndSkeletonfbx_Head_Skeleton`.
- **rest_maxdelta = 0.00002** относительно хендоффа → тот же bind-скелет, что у `SK_Armor_T*`/`SK_Cloth_T0_*`.
  Значит `BP_Elder` наденет модули через Leader/Master Pose, кости НЕ переименованы.
- **unweighted = 0** на всех модулях. vgroups: Head 2, Torso 16, Legs 12 (веса навесной геометрии — KDTree с ближайшей вершины базового тела).
- **Позовый чек (`_pose_elder.log` + renders_elder/Elder_pose_*):** при сгибе плеч/локтей/шеи/бёдер/колен
  шапка/борода/жилет/пуговицы/ботинки деформируются вместе с телом — НЕ разлетелись (кости НЕ ×100, урок 07-06).

## Допущения (явно)
1. **Седина `#ADA492`** (теплее палитрового `#9AA08C`): `#9AA08C` в QC-рендере читался холодным мятным;
   референс задаёт тёплое серебро. game-lead подтвердил оставить (07-09).
2. **Ремень — на модуле Legs** (верхний band z>0.873 + пряжка), как у существующей экипировки T0/T1/T2.
3. Борода/шапка/жилет — тонкие/односторонние аппликюры (лофт-оболочки) → в UE материал `M_Elder_Flat`
   пометить **Two-Sided** (прецедент шарфа T2/подбородочного ремня T3).
4. Пропы (посох) НЕ включены — вопрос §8.5 спека открыт; паспорт покрывает одежду по 3 слотам.
