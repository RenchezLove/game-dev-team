# Abandoned Car — модульный комплект (задел под мастер-Blueprint)

Узнаваемый силуэт классической «Лады»-седана (ВАЗ-2105/2107): три объёма, прямые
линии, прямоугольная решётка + прямоугольные фары, хром-бамперы. Каждая навесная
часть — отдельный меш со своим FBX; пивот навесных частей лежит НА ОСИ ПЕТЛИ,
чтобы параметрический Blueprint открывал/снимал части простым поворотом/скрытием
без перемоделирования.

## Схема сборки — КООРДИНАТЫ UE (кузов origin = центр на земле; нос = -Y)

Про систему координат: первая версия таблицы была в Blender-координатах (нос +Y) —
это была ошибка доки, потребитель таблицы работает в UE, а FBX-импорт UE зеркалит Y.
Знаки Y ниже уже перевёрнуты под UE. Направления открывания (знаки поворотов) при
зеркале тоже меняются — подбирать знаком по месту. Посадка Hood/Trunk по Z сверена
game-lead живой подгонкой в собранной UE-сцене (2026-07-04); двери/колёса/остальное —
расчётные значения, замечаний по посадке не было.

| Door_FR | ( 0.80, -0.470, 0.315) | Z |
| Door_RL | (-0.80, 0.375, 0.315) | Z |

на рендерах) давал 0.830/0.843, в UE заподлицо получилось на 0.880/0.893. Причина дельты
из геометрии не выведена — значения приняты по живой UE-сцене (живой артефакт главнее).
Если при пере-сборке посадка разойдётся — сначала проверить Z кузова (origin на земле)
и не повёрнута ли панель по yaw вместо зеркала.

кузов rx -1.8° и z -0.06).

## Контракт материалов (для UE, за game-lead)

- **M_CarPaint** (кузов, двери, капот, багажник): vcol RGB = ГОТОВЫЙ вид (выцветшая
  голубая краска + ржавый тон в зоне пятен + тёмная окантовка-уплотнитель окон) —
  с обычным vcol-материалом (M_VColor) ассет сразу выглядит правильно.
  vcol A = МАСКА «НЕ-КРАСКИ»: 0 = перекрашиваемая параметром краска, 1 = фиксированный
  цвет из vcol RGB (ржавчина И тёмный уплотнитель рамок окон).
  Параметрический цвет кузова: **BaseColor = lerp(BodyColorParam, VertexColor.RGB,
  VertexColor.A)** — рекомендованный вариант (ржавчина и уплотнитель остаются как есть).
  Вариант с константой RustColor вместо VertexColor.RGB НЕ использовать — он перекрасит
  тёмные рамки окон в ржавый.
- **M_CarProps**: плоские vcol-цвета (ADR-032) — хром, фары/фонари, салон, резина,
  ржавые диски, бетон, царапины, днище. Opaque.
- **M_CarGlass**: полупрозрачное мутное серо-голубое, Two-Sided (стёкла — плоскости).
- Царапины-декаль: тонкий меш, Two-Sided не обязателен (нормаль наружу), полезен offset.

## Явные допущения (плейсхолдер-уровень)

- Боковые стёкла «выбиты» (рамки дверей пустые) — по рефу 3.png; отдельный меш стекла
  только лобовое+заднее.
- Дверные/капотные проёмы = неглубокие тёмные ниши, НЕ полый кузов насквозь (под
  top-down камеру читается как проём; полая часть — только кабина под остеклением,
  салон с сиденьями/торпедо/рулём виден через окна).
- Тормозных барабанов за снятым колесом нет; арка без колеса — сквозной тёмный тоннель.
- Ржавчина процедурная по вершинам (пятна+кромки+пороги+арки), детальность ограничена
  плотностью сетки — крупные фасеточные пятна в стиле ADR-032.
