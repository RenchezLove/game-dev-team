## 0. Общее (обе локации)
- **Дискретные точки-энкаунтеры (GDD §5 РЕШЕНО 2026-06-22, ADR-024):** враги спавнятся по подходу игрока; локация = МЕСТО (геометрия + пропы), НЕ статичные враги. Логово — север, база — юг; деревня между ними — мирная.
- **Тон:** мрачноватый survival (STALKER / Last Day on Earth); опасность — **цветом, не кровью** (GDD ч.2); юмор — деталью среды/текстом, не клоунадой.
- **Стиль:** низкополи, крупные фаски, флэт-монохром + baked AO. **1 материал на пропс** (mobile), без normal/parallax/тяжёлых нод, без Lumen; Mobile/Forward + запечённый свет (`mobile-optimization.md`).
- **Полибюджет (GDD ч.2):** пропсы **200–1500 трис**, камни/флора **100–600 трис**. (`mobile-optimization.md` per-asset чисел не даёт — числа из GDD ч.2.)
- **Палитра** — только утв. GDD; камень/дерево согласованы с house-material-board.
- **Реюз / Foliage:** бочка `assets/iron_barrel` (есть на диске) — для базы; Foliage-кисти (Этап C5) — трава/кусты вокруг обеих; камни — из одной библиотеки фасеточных rock-мешей с общим материалом.

## 1. ЛОГОВО ВОЛКОВ (север)
**Роль / читаемость:** «звериное логово» — узнаётся сверху по тёмному устью норы/пещеры в скальном выступе + кольцо валунов + разбросанные кости.

**Силуэт / форма [ВАРИАНТ]:** скальный выступ/холм с **тёмным устьем-входом** (нора или мелкая пещера); вокруг — фасеточные валуны; утоптанная земля-проплешина (само логово). Север → холоднее и темнее, в тени хвои.

**Материалы (палитра GDD, холодный камень — как крыша в house-board):**
- Камень: Faded Sage `#9AA08C` (освещённая грань) · Concrete `#6E6A60` (тень) · Cold Steel `#5A6470` (глубокая тень).
- Устье/глубина пещеры: Pine Shade `#2B3A2C` — почти чёрное.
- Земля логова (вытоптано): Dry Earth `#7D6A4E`.
- Мох на камне: Moss Field `#3F5A31` малыми пятнами.

**Пропы:** костяная куча / разбросанные кости (замена удалённого `SM_BonePile`) — Bone Ink `#E7E4D8` приглушённый; обглоданные ветки; редкие следы. Скупой намёк крови Muted Blood `#8A2F2A` — **[ВАРИАНТ]**, минимально (GDD: кровь скупо).

**Top-down:** холодный камень + тёмное устье + светлые кости = «логово» с дистанции; холодный тон отделяет от тёплой деревни/дороги.
**Тон:** тихая звериная угроза, без чернухи.

## 2. БАЗА БАНДИТОВ (юг) — ОКРУЖЕНИЕ вокруг сарая
> Сам **сарай лепит modeler первым проходом** — здесь только ambiance/props/настроение «площадка занята бандитами».

**Роль / читаемость:** узнаётся по **костру** + барахлу + **рыжим акцентам-меткам территории** (тот же рыжий, что нашивка/армбанд бандита-врага = сигнатура угрозы).

**Пропы (layout вокруг сарая):**
- **Костёр** (центр сходки): Amber Loot `#E0A32E` свечение + Rust Alarm `#C64B2C` угли + тёмная камень-обкладка; вокруг — ящики/брёвна как сиденья.
- **Ящики/крейты:** Timber `#8A5A32` / Dry Earth, потёртые.
- **Ржавые бочки:** РЕЮЗ `assets/iron_barrel`; Cold Steel `#5A6470` + рыжие потёки Rust Alarm `#C64B2C`; часть горелые/мусорные.
- **Забор/ограждение:** выветренное дерево (как house-board) или сетка; частично сломан.
- **Мусор/барахло:** тряпьё, старые покрышки, канистры — маркеры обжитости.
- **Палатка/тент [ВАРИАНТ]** (GDD §5 «палатки/костры»): брезент приглушённый хаки / Concrete.

**Акцент-цвет = РЫЖИЙ `#C64B2C` Rust Alarm** — сигнатура бандитской угрозы (нашивки/метки/граффити/тряпки). Тёплый янтарь костра `#E0A32E` — отдельная роль «жильё/огонь», не угроза.

**Юмор деталью [ВАРИАНТ — на утв., текст НЕ выдумываю]:** кривая табличка/граффити («частная территория» / абсурд) — GDD «юмор текстом и реквизитом». Конкретную формулировку даёт Ринат; пока плейсхолдер.

**Top-down:** тёплое пятно костра + кучность барахла + рыжие метки = «обжитая опасная точка»; контраст к мирной деревне.
**Тон:** угроза со стёбом, не хоррор (GDD: бандит menacing but stylized, slightly darkly comedic).

## 4. Открытые вопросы Ринату
1. **Форма логова:** пещера в скале vs земляная нора-холм vs расщелина меж валунов? (рек. скальный выступ с тёмным устьем).
2. **Кровь** у логова/базы — да, скупо vs совсем нет?
3. **Палатка/тент** на базе — нужен или хватает сарая + костра + ящиков?
4. **Табличка/граффити** (юмор) на базе — давать? если да — текст даёт Ринат.
5. **Степень «замусоренности» базы** — лёгкий обжитой беспорядок vs свалка?
