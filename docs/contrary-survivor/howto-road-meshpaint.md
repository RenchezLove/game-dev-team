# Как нарисовать дорогу кистью (Mesh Paint / Vertex Paint) — UE 5.5

**Как устроена дорога.** Пол уровня — меш `SM_GroundPlane` (сетка 360 м, вершины через ~2 м).
Материал земли `M_GroundBlend_WIP` смешивает две текстуры по **цвету вершин (vertex color)**:
`BaseColor = Lerp(трава, грязь, Alpha = VertexColor)`.
- Вершины **ЧЁРНЫЕ (0,0,0)** → трава.
- Вершины **БЕЛЫЕ (1,1,1)** → грязь = дорога.

То есть «нарисовать дорогу» = закрасить вершины пола белым там, где идёт дорога. Это и есть
vertex paint (в UE инструмент называется **Mesh Paint → Colors**).

## Пошагово (мышкой, в редакторе)

1. Открой уровень `L_World_C` (он уже открыт).
2. Выдели на сцене актёр пола **`GroundPlane`** (в Outliner или кликом по земле).
3. Вверху-слева вьюпорта переключи режим: выпадающий список режимов (по умолчанию **Selection**)
   → выбери **Mesh Paint**. (Либо меню: режим редактирования → Mesh Painting.)
4. В панели слева у Mesh Paint выбери вкладку **Colors** (покраска цветом вершин), а не Weights/Textures.
5. Настрой:
   - **Paint Color = белый** (1,1,1) — это «дорога/грязь».
   - **Erase Color = чёрный** (0,0,0) — это «трава» (стирание дороги).
   - **Channels**: оставь включёнными R, G, B (красим по всем каналам — материал берёт цвет целиком).
   - **Brush Size** — диаметр кисти (под ширину дороги, ~600–900 для дороги ~6–9 м).
   - **Strength = 1.0**, **Falloff** — мягкость края (0.3–0.5 для плавных обочин).
6. Рисуй по полу:
   - **ЛКМ (зажать и вести)** — красит белым = появляется дорога.
   - **Shift+ЛКМ** (или режим Erase) — красит чёрным = возвращает траву (стираешь лишнее).
7. Веди кисть плавными линиями по маршруту-кресту (деревня запад → перекрёсток → север/юг/восток).
   Помни: к логову (восток) дорога **обрывается на полпути** (тропа теряется — по схеме).
8. Когда готово — **сохрани уровень** (Ctrl+S).

## Важно
- Плотность вершин пола ~2 м → дорога рисуется с шагом ~2 м; для гладких краёв веди кисть медленно,
  кисть пошире. Если нужно мельче/глаже — пересоберём пол гуще (скажи game-lead).
- Mesh Paint красит **vertex color этого размещённого пола** (override на актёре) — это нормально,
  дорога привязана к конкретному полу на уровне.
- Эталон кривизны дорог — `docs/contrary-survivor/ui/scheme-map.png` (почти прямые рукава, лёгкая
  органика; крест из 4 рукавов от перекрёстка; восток к логову обрывается).

## Если хочешь, чтобы дорогу клал game-lead (программно)
Альтернатива кисти — покраска vertex color скриптом (Geometry Script), уже отработана в этой
сессии. Минус: рисует геометрически (полосы по формуле), не «от руки». Кисть даёт живее.
