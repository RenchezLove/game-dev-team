# Спек-лист: 4 деревенских пропса (ЧЕРНОВИК / на отбор)

> Автор: `concept-artist`. Статус: **черновик — на отбор Рината через game-lead**. Источник раскладки: `docs/contrary-survivor/scheme-village.png` (утверждена). Это текстовое ТЗ для `modeler-3d` (моя роль — ADR-004, фигуративную модель не делаю, описываю формы и параметры).

## Общие правила (для всех 4 пропсов)
- **Стиль** — как у прошлых деревенских/бандитских пропсов (`E:/ForGameLead(Materials)/demo-assets/SM_Bandit*.fbx`, `SM_Village*`): низкополи, без мелкой деформации, формы читаемы силуэтом сверху (игра top-down). Выветренное дерево, выцветшая ткань, без глянца.
- **Масштаб** — реальный, в метрах (в UE 1 м = 100 единиц; задавать в Blender метры, экспорт FBX с применённым масштабом, без авто-скейла на импорте).
- **Origin (точка отсчёта)** — в ОСНОВАНИИ пропса по центру, на уровне земли (Z=0). Объект ставится на землю без проседания/парения.
- **Ориентация** — +Z вверх (UE/Blender Z-up), фронт по +Y (как у существующих SM_*). Меш триангулирован, нормали наружу, без вывернутых граней.
- **Материал** — экономно: 1 материал на пропс (максимум 2, если ткань/металл отдельным), плоская заливка + запечённый AO (ambient occlusion) или vertex-tint для объёма. Без normal/parallax, без Lumen (цель — слабый Android, см. `mobile-opt.md`).
- **Палитра (cs-palette, HEX):** дерево-база Timber `#8A5A32`; тёмные щели/тень Pine Shade `#2B3A2C`; выветренное серое дерево Faded Sage `#9AA08C`; земляной тёплый Dry Earth `#7D6A4E`; светлый свежий срез дерева `#C9A86A` (тёплый, с тёмными кольцами); ткань выцветшая — Faded Sage `#9AA08C` / Dry Earth `#7D6A4E` / Bone Ink `#E7E4D8`; металл Cold Steel `#5A6470`; ржавчина/акцент Rust Alarm `#C64B2C`; верёвка/джут Dry Earth `#7D6A4E`.
- **Коллизия** — простой бокс/капсула на основание (по габариту), не по полигонам. Тент проходим (декор), коллизия только на столбы по желанию.

## 1. Тент-навес частичный (market awning / tarp)
Назначение: навес над прилавком торговца / у двора. ЧАСТИЧНЫЙ (не полный шатёр) — крыша-скат с одной стороны, открытая спереди. Вид сверху: брезент НЕ закрывает того, кто под ним (важно для top-down — торговца должно быть видно), поэтому навес сдвинут к задней кромке.
- **Габариты:** ширина ~2.2 м, глубина ~1.4 м, высота передней кромки ~2.0 м, задней ~2.4 м (лёгкий скат). Опора — 2 передних жерди + крепление к задней (стена/2 задние жерди).
- **Ключевые формы:** 4 жерди-стойки (тонкие, Ø ~6–8 см, цилиндр 5–6 граней) + перекладина сверху + натянутый брезент (плоскость 3×3 / 4×4 сегмента с лёгким провисанием посередине и по краям, чтобы читалось «ткань», не доска). Края брезента слегка волнистые/обвисшие. Можно 1–2 верёвочные растяжки от угла к колышку (необязательно).
- **Полибюджет:** ~150–300 трис.
- **Материалы:** жерди — дерево (Timber base, Faded Sage выветривание). Брезент — выцветшая ткань: основной Faded Sage `#9AA08C` ИЛИ Dry Earth `#7D6A4E`, с пятнами грязи/потёртостями; допускается 1 тонкая полоса-акцент. Без ярких цветов.
- **Заметки:** скат ориентировать так, чтобы прилавок (отдельный ассет/реюз ящиков) вставал под открытую переднюю сторону. Двусторонний материал у брезента (видно с изнанки).

## 2. Поленница (woodpile)
Назначение: запас дров у дома (быт). Прямоугольная кладка поленьев.
- **Габариты:** длина ~1.4 м, высота ~0.9 м, глубина ~0.5 м.
- **Ключевые формы:** поленья уложены штабелем; ВИДИМЫЕ ТОРЦЫ-СРЕЗЫ обращены наружу по длинной стороне (характерный рисунок «много кружков-срезов»). Реализация низкополи: фронтальный ряд — 10–16 коротких цилиндров-поленьев (Ø ~10–12 см, 6 граней) с торцами; внутреннюю массу НЕ моделировать поштучно — заполнить блок-формой с теми же торцами по фасаду (фейк-глубина). Верх — пара поленьев внахлёст, силуэт неровный (не идеальный кирпич).
- **Полибюджет:** ~200–400 трис.
- **Материалы:** боковая кора — дерево (Timber `#8A5A32` + тёмные щели Pine Shade `#2B3A2C`, местами серое Faded Sage). ТОРЦЫ — светлый свежий срез `#C9A86A` с намёком на годовые кольца (тёмный центр/штрихи в текстуре или vertex). Контраст «кора тёмная / срез светлый» — главный читаемый признак поленницы.
- **Заметки:** допустимо 2 LOD-варианта длины (1.0 м и 1.5 м) если дёшево; иначе один ~1.4 м.

## 3. Бельевая верёвка (clothesline)
Назначение: оживляет двор. 2 столба + натянутая верёвка + висящие вещи.
- **Габариты:** пролёт между столбами ~2.5 м, высота столбов ~1.8 м. Верёвка провисает (катенария) на ~10–15 см.
- **Ключевые формы:** 2 деревянных столба (Ø ~8 см, цилиндр 5–6 граней, можно с косой подпоркой у основания). Верёвка — тонкий вытянутый меш (узкая призма/лента, НЕ цилиндр высокого разрешения), с провисом. 2–3 тканевые вещи на верёвке (простыня/рубаха/штаны) — плоскости с провисанием через верёвку (перегиб сверху), лёгкая волна по низу. Вещи разной ширины для ритма.
- **Полибюджет:** ~120–250 трис.
- **Материалы:** столбы — дерево (Timber + выветривание). Верёвка — джут Dry Earth `#7D6A4E`. Ткань — выцветшие: Bone Ink `#E7E4D8`, Faded Sage `#9AA08C`, Dry Earth `#7D6A4E` (по одной на вещь, приглушённые). Двусторонний материал у ткани.
- **Заметки:** вещи не должны касаться земли (низ ≥ 0.6 м над Z=0). Origin — по центру между столбами на земле.

## 4. Колода с топором (chopping block)
Назначение: место для рубки дров у дома. Пень-колода + воткнутый топор + пара поленьев рядом.
- **Габариты:** колода Ø ~0.35–0.4 м, высота ~0.4–0.5 м. Топор торчит вверх ~0.4 м над колодой. Общий габарит группы ~0.7 м.
- **Ключевые формы:** колода — короткий цилиндр (8–10 граней) с плоским верхом (видна текстура торца-среза с кольцами и зарубками от топора). Топор — топорище (вытянутый бокс/призма, слегка изогнутое) + лезвие-клин (плоский трапециевидный клин), воткнут под небольшим углом в верх колоды. Рядом 1–2 расколотых полена (короткие призмы с клиновидным сколом) лежат на земле.
- **Полибюджет:** ~150–300 трис.
- **Материалы:** колода — кора по боку (Timber + Pine Shade щели), верх — светлый срез `#C9A86A` с тёмными зарубками. Топорище — дерево (Timber/Dry Earth). Лезвие — металл Cold Steel `#5A6470` с лёгкой ржавчиной Rust Alarm `#C64B2C` (пятна/кромка). Поленья — как поленница (кора + светлый скол).
- **Заметки:** топор — отдельный элемент того же меша (не разбирать на части), но геометрически читаемый силуэтом сверху (лезвие поперёк, топорище наружу).
