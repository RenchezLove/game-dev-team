### ⏳ D — Оружие (визуал + механика) + **СОЧНОСТЬ БОЯ** `[cpp-dev + modeler/unreal]`
- 🎯 **ПРИНЦИП ПЛОТНОСТИ БОЯ (Ринат 07-01, ADR-037):** одновременно активны **≤2–3 врага** (LDoE-ощущение: вдумчивый читаемый бой, честнее по боевой камере, лучше для теста). Стая/группа может СУЩЕСТВОВАТЬ (4 волка у логова), но вступает в бой **врастяжку — через энкаунтер-дизайн** (радиус агра, расстановка, тропы; связано с «поводком» D7 и точками спавна `AMasterEnemyBase`), а НЕ «убрать половину волков». Бандиты (3) уже почти в рамках.
- ⏳ D1–D3. Держание/мазл-флэш/трассер пистолета; **удар ножа передним взмахом/сектором** — задевает **1–2 цели ВПЕРЕДИ** (несколько за удар — ок), но **НЕ круговой 360° урон вокруг игрока** (отменяет прежний «радиусный урон холодного», ADR-037). Телеграф удара — по желанию передней дугой, не кольцом. Если на плейтесте нож слаб против 2–3 — расширить передний сектор, НЕ делать круг.
- ✅ D4. Модели оружия приняты (пистолет 240 трис, нож 80 трис).
- ⏳ **D5. Сочность боя (НОВОЕ, дёшево):** всплывающие **цифры урона** (world-space виджет) + **хитстоп** (микро-заморозка удара — кратким замедлением времени) + **тряска экрана** (штатный `UCameraShakeBase`). Мазл-флэш/радиус-удар уже в D1–D3. ⚙️ всё — стандартные средства UE, риск низкий. Влияет на «вменяемый вид», поэтому в Группе 1.
- ⏳ **D6. Бандиты — огнестрел + БОЕВАЯ КАМЕРА (ПАКЕТОМ; НОВОЕ, Ринат 07-01; ADR-035):**
  - Бандиты применяют **огнестрел (пистолеты)** — стрелковая атака с дистанции. ⚠️ **ФАКТ (код `EnemyAIController.cpp`):** сейчас ВСЕ враги ближники (`AttackRange 90 см`, урон вплотную), стрелкового режима НЕТ → новая механика (дистанция/кулдаун/точность; реюз `ARangedWeapon`/`APistol` либо упрощённый enemy-fire). Стоимость: **УМЕРЕННО**.
  - **Правило честности:** бандит НЕ стреляет, если он вне кадра камеры. Дёшево (проверка «на экране» перед выстрелом: `WasRecentlyRendered`/проекция в вид). НЕ путать с `LineOfSightTo` (тот — сквозь стены, для обнаружения).
  - **Боевая камера (ADR-035):** в бою камера перестаёт смотреть вперёд и слегка смещается к ближайшей угрозе/центру угроз — держит стрелков в кадре. **БЕЗ зума** (перф на слабом Android). Краевые стрелки HUD (`DrawNPCEdgeArrow` — СУЩЕСТВУЮТ, проверено) реюзим как маркер «стрелок» за кадром. Стоимость: **УМЕРЕННО**, перф-дёшево.
  - **Делать ПАКЕТОМ:** огнестрел без честной камеры бьёт из-за края → бесит и мажет сигнал удержания, поэтому вместе. **В Build 1 (решение Рината 07-01):** без огнестрела бандиты = копия волков (оба только вплотную) — неинтересно; поэтому огнестрел + боевая камера идут в первый билд.
- ⏳ **D7. Ограничения ИИ: безопасная деревня + «поводок» (НОВОЕ, Ринат 07-01; ADR-036) — В Build 1:**
  - **Безопасная деревня:** враги не заходят; у границы замедление/пауза/возврат (читаемо, не «стена»). ⚠️ **ВАЖНО про механизм:** классы обхода деревни ЕСТЬ в КОДЕ (`NavArea_Village` + фильтр `ExcludeVillage`, ИИ применяет — проверено по исходникам). НО **размечена ли зона деревни объёмом (Nav Modifier Volume) на карте `L_World_C` — НЕ ПРОВЕРЕНО** (проверю в редакторе/PIE). Подход как задумано: навмеш на всю карту + пометить деревню зоной-исключением. Дыра: прямая погоня-fallback (`AddMovementInput`) игнорит навмеш → нужен ещё явный запрет по границе деревни (не только nav). Стоимость: **УМЕРЕННО**.
  - **«Поводок»:** враги гонятся в радиусе от своей базы; ушёл далеко → возврат (не до последнего). Внутри — догоняют (закрывает кайтинг). Полный отход = валидная тактика. ⚠️ поводка в коде НЕТ (погоня только по `DetectionRange`+видимость) → новое. Стоимость: **ДЁШЕВО-УМЕРЕННО**.
  - **Правило «не стрелять вне кадра»** — см. D6 (проверка «бандит на экране» перед выстрелом). Всё D7 — в первый билд.

### ⏳ E — Прогрессия: **броня** `[cpp-dev]`

## ГРУППА 3 — «Монетизация» (BUILD 2, после валидации удержания; директива: ПОТОМ)

### ⏳ H — Лагерь учёных + rewarded-реклама + revive `[cpp-dev + modeler/unreal + game-lead]`
- ⏳ **H1. Лагерь учёных (диегетическая rewarded-реклама).** Источник истины GDD ч.5/ч.11: «Лагерь учёных (2-3 учёных): аномалии; относительно безопасно» + реклама = «эксперименты учёных, добровольный просмотр за валюту, не более 3 подряд, перерыв 3–5 мин». Механика: подход → учёные предлагают эксперимент → надевают VR-шлем → крутится реклама (15–30 с, длительность задаёт сеть) → снимают шлем, благодарят, платят игровой валютой.
  - **Оценка стоимости (калибровка):**
    - **Арт локации — в основном РЕЮЗ, дёшево:** учёные = модульный гуманоид с другим цветом/одеждой (новый арт не нужен); палатки = реюз тента/сарая; VR-шлем = мелкий проп (дёшево); аномалии = простой VFX/реюз. Размещение — game-lead/Ринат.

    - ⚠️ **ГЛАВНАЯ стоимость/риск — ad-SDK (VK Ads/myTarget/RuStore) в UE 5.5 Android — НЕ ПРОВЕРЕНО.** Скорее всего сторонний плагин, объём неизвестен. Общий с revive (H2).
  - **Рекомендация по билдам:** **лагерь учёных = Build 2.** Первая когорта мерит удержание + дешёвый сигнал готовности к рекламе (см. G, opt-in-заглушка). Реальный диегетический лагерь + реальный ad-SDK — во втором заходе, когда удержание подтверждено. **Совпадает со склонностью издателя (удержание-first).**
- ⏳ **H2. Revive-за-рекламу (ВТОРИЧНО относительно H1).** Идея принята; нельзя воскрешать в толпу врагов. **Предложение (на решение Рината):**
  - **Рекоменд. вариант:** воскрешение НА МЕСТЕ + **неуязвимость ~2–3 с + отброс врагов** (impulse) от игрока, диегетически — «аномальный выброс отталкивает» (дёшево, реюз VFX). Плюс: игрок остаётся в гуще действия, темп не рвётся.
  - **Фолбэк (если рискованно):** воскрешение **у костра** (реюз существующей точки респауна) — гарантированно безопасно, но телепорт из боя.
  - **Флейвор-вариант:** «аномалия выдёргивает в безопасную точку» — тот же телепорт с обёрткой; VFX добавляется слоем позже.

## 3. Порядок и зависимости (единая последовательность)
```
✅ 0 → A → B
        ↓
🔄 C  (реорг + навмеш-бейк = квесты работают на новой карте)
        ↓
⏳ D  (оружие + радиусный удар + сочность боя = вменяемый вид)
        ↓
⏳ E  (броня: урон + магазин = прогрессия работает)
        ↓   ←—— конец Группы 1 (директива «сначала»)
⏳ F  (онбординг + ежедневка + аналитика)          [Группа 2]
        ↓
⏳ G  (Android-пак + замер) ====> BUILD 1 (мерит D1/D7)
        ↓   ←—— оценка удержания на когорте 1
⏳ H  (лагерь учёных + rewarded + revive) ====> BUILD 2 (мерит готовность к рекламе)   [Группа 3]

Параллельно/после, НЕ блокирует тест:  I (UMG)   J (DataTable)   K (финал каждого билда)
```
**Логика зависимостей:**
- Навмеш (C7) → враги спавнятся → квесты работают. Всё остальное после этого.
- Сочность (D5) и броня (E) не трогают боевой цикл, но нужны для «вменяемого вида»/прогрессии — Группа 1.
- Аналитика (F3) на существующих делегатах; должна быть в Build 1, иначе нечем мерить D1/D7.
- Android (G) — на критическом пути Build 1 (тест раздаётся на телефоны), а не в финале.
- Монетизация (H) после валидации удержания; ad-SDK — общий блок для H1/H2.

## 5. Открытые вопросы — Ринату (решения)
1. **Лагерь учёных — Build 1 или Build 2?** Рекомендую **Build 2** (удержание-first; арт в основном реюз, но ad-SDK дорог/рисков). Build 1 мерит готовность к рекламе дешёвой opt-in-заглушкой.
2. **Revive-за-рекламу — какой вариант?** Рекомендую: на месте + неуязвимость 2–3 с + отброс врагов («аномальный выброс»). Фолбэк — у костра.
3. **Провайдер аналитики и рекламной сети** (AppMetrica/Firebase/RuStore; VK Ads/myTarget/RuStore) — бизнес/интеграционная развилка. Нужна разведка осуществимости в UE 5.5; дам факт до закладки.
4. **Камера в бою + поведение врагов — РЕШЕНО Ринатом 07-01 (ADR-035/036); ВСЁ в Build 1.** Камера: два режима (исследование look-ahead / бой = смещение к угрозе, без зума, краевой маркер «стрелок»). Враги: безопасная деревня + поводок у базы + не стреляют вне кадра. Огнестрел бандитов — тоже Build 1 (без него бандиты = копия волков). Публишер-вопрос по камере (`publisher-camera-question.md`) больше НЕ блокирует — факультативная справка.
   - ⚠️ **Проверить в PIE/редакторе при реализации:** реально ли размечена зона деревни объёмом на `L_World_C` (классы `NavArea_Village` в коде есть, разметка на карте — НЕ ПРОВЕРЕНО) + закрыть дыру прямой погони-fallback (игнорит навмеш).
