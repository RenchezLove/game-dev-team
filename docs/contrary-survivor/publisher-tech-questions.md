# Вопрос издателю: аналитика, rewarded-реклама, раздача теста (Contrary Survivor)

> **Дата:** 2026-07-01 · Автор: game-lead (через Рината) · Контекст: `demo-plan-v2.source.md` (F3, G, H).
> Направление плана согласовано с вашим уклоном: **удержание-first.** Просим ваши наработки по 3 техническим пунктам, чтобы не дублировать разведку.

## Куда движемся (кратко)
- **Build 1 (первая когорта, ~200–300 установок):** играбельная петля + сочность боя + онбординг + ежедневка + **аналитика (D1/D3/D7)**, на **Android**. Готовность к рекламе меряем дёшево — диегетическим предложением с логом согласия (opt-in), БЕЗ реальной рекламной сети.
- **Build 2:** реальная rewarded-реклама через **лагерь учёных** (диегетика: подход → VR-шлем → ролик → оплата валютой) + «второй шанс за рекламу».

## Что просим (у вас, вероятно, это уже есть)
1. **Аналитика для UE 5.5 + Android/RuStore.** Какой SDK вы рекомендуете/уже проверяли для метрик удержания D1/D3/D7 и событий (старт-сессии, убийство, сдача квеста, покупка, смерть)? Варианты на нашем радаре: AppMetrica (Яндекс), Firebase, встроенная аналитика RuStore. Есть ли рабочий путь интеграции в Unreal (плагин/обёртка)?
2. **Rewarded-реклама для UE 5.5 + Android/RuStore.** Какую рекламную сеть советуете (VK Ads / myTarget / RuStore Ads / иная) и есть ли проверенный способ подключить rewarded-формат в Unreal (готовый плагин или потребуется нативная обёртка под Android)? Это наш главный технический неизвестный по монетизации.
3. **Раздача тест-билда когорте.** Как удобнее раздать Android-билд на ~200–300 установок для замера удержания — закрытое тестирование RuStore, прямая ссылка/APK, иной канал? Есть ли у вас требования к сборке (подпись, версия, минимальное устройство)?

## Справочно (уже решено у нас, ответа не требует)
- **Камера в бою** — решена внутри (два режима: исследование look-ahead / бой — смещение к угрозе, без зума + правило «не стрелять по игроку вне кадра»). Отдельный вопрос по камере (`publisher-camera-question.md`) больше не срочный; ваше мнение примем, но не ждём.
