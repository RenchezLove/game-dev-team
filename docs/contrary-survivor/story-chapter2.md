## Ход главы
1. Герой приносит ноутбук учёным. Руководитель лагеря Вера: расшифруют, но пусть и он поможет — людей мало, работы много. Задание даётся СРАЗУ (Ринат: игроку не нужно ждать день, учёные сразу предлагают работу в обмен на расшифровку).
2. Задание «Образцы из аномалий» (подробно ниже). Пока герой ходит, учёные взламывают ноутбук. По возвращении Вера: бандиты возили Куратору ящики с такими же образцами.
3. Вера замечает: рядом с героем приборы сходят с ума. Задание — расставить по округе датчики.
4. По дороге на героя нападает наёмник Куратора и перед боем называет героя по имени, которого герой не помнит.
5. Герой возвращается к Вере, она открывает последний файл ноутбука: фотография героя рядом с самой Верой. Они были знакомы, а она молчала. Конец главы.

## Задание «Образцы из аномалий» (идея Рината, уточнения лида приняты)
- На карте отравленная (химически) зона рядом с базой учёных, зеленоватый туман.
- Учёные выдают баллоны с воздухом. У края зоны кнопка «Надеть дыхательный аппарат».
- После нажатия поверх экрана — стекло маски (слегка запотевшее и поцарапанное), это картинка поверх экрана, не тяжёлая обработка кадра (слабые телефоны).
- Шкала воздуха убывает; воздух кончился — здоровье тает. Без маски в зоне здоровье тает быстро.
- Детектор аномальных образований (как в S.T.A.L.K.E.R.): пищит тем чаще, чем ближе образец, плюс полоска силы сигнала. Стрелки-указателя нет.
- В зоне три светящихся образца, подбираются касанием, сдаются Вере.
- Картинки (стекло маски, значки баллона и детектора) — через OpenAI.
