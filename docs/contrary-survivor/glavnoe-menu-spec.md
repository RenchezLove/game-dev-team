# Главное меню и настройки — утверждённый состав (Ринат, 2026-08-06, дословно «можно отправлять как есть»)

> Статус: дизайн-правда для этапа «полное главное меню». По заданию издателя (ADR-059) полное меню
> НЕ входит в первую выкладку RuStore — в ней только минимум (экран согласия, строка «Политика
> конфиденциальности» в паузе, номер версии, автовыбор качества графики). Этот документ — объём
> следующего этапа.

## Главное меню — состав
1. **«Продолжить»** — загружает последнее сохранение. Если сохранения нет, пункт **не показывается
   вовсе** (не гаснет серым).
2. **«Новая игра»** — с подтверждением, если сохранение существует: «Прогресс будет удалён».
3. **«Настройки»**.
4. **«Сообщество»** — ссылка на Telegram; адрес берётся **из конфига**, не зашит в код.
5. **«Выход»**.
6. Внизу мелким шрифтом: **номер версии сборки** и ссылка **«Политика конфиденциальности»**.

## Поведение
- При самом первом запуске после установки меню **не показывается**: игрок попадает сразу в интро.
  Меню появляется со второго запуска.
- Фон статичный, без анимаций.
- Возврат в меню из паузы — с подтверждением, если прогресс не сохранён.

## Настройки — графика
- При первом запуске качество выставляется **автоматически** по мощности устройства.
- Список ручных настроек графики — на усмотрение команды (лид предложит состав).
- Рассмотреть пункт **«разрешение экрана»** (Ринат просил проработать вопрос).

## Настройки — остальное
- Громкость музыки и громкость эффектов — **два раздельных ползунка**.
- Чувствительность управления.
- Прозрачность экранных кнопок.
- Вибрация — вкл/выкл.
- **«Сообщить об ошибке»** — ведёт в Telegram, с просьбой указать номер версии сборки.
- **«Сбросить прогресс»** — с двойным подтверждением.

## Техническое замечание Рината (важно для планирования)
«Продолжить» невозможно сделать без загрузки сохранения при старте, поэтому меню и загрузку сейва
делать **одной работой**. Примечание лида: загрузка при старте и экран «Продолжить»/«Новая игра»
уже реализованы волной Б3 (2026-08-05/06) — меню строится поверх этой основы, переделка не нужна.
