# Ответ производителя на бриф издателя (RuStore / монетизация / удержание)

> **Дата:** 2026-07-01 · Автор: game-lead · Источники: `GDD.md`, `demo-plan.source.md`, `decisions.md`, реальный гейм-репо (греп кода + листинг Content, проверено живьём).
> Принцип: только факты с пруфом. Не сделано — так и написано.

## ⚠️ Стратегическая рамка (важно понять сразу)
Текущие «70% к демке» построены по **контент-first** плану (бой → квесты → UI). Издатель ставит **retention-first** (удержание = деньги). Это **наши самые слабые зоны**: онбординг, ежедневки, мета-прогресс, «сочность», монетизация — почти всё **с нуля**. Значит до **доходной** версии дальше, чем до «играбельной демки»; план демки нужно пере-приоритизировать под удержание (предложу отдельно, решает Ринат).

## A. Дизайн-направление (что есть / где провисает)

**1. Core loop до «вкусного».**
- *Есть:* hitscan-стрельба (пистолет+нож), урон/смерть; **звук подключён в коде** (выстрел, замах ножа, шаги, рык волка при атаке, звук урона, лесной амбиент); **кровь-декали при попадании** (BP_BloodDecal + 3 текстуры).
- *Провисает:* **нет всплывающих цифр урона, нет тряски экрана, нет мазл-флэша/VFX-частиц, нет лут-фонтана, нет хитстопа** (проверено грепом — в коде отсутствуют). Бой работает, но «сухой». Первые 60 сек: подход к логову → спавн врагов по триггеру → клик-захват → стрельба со звуком и декалью крови, но без цифр/тряски/фонтана. Лут — обычный подбор, не «фонтан».

**2. Онбординг (первые 5 минут).**
- *Есть:* завязка (амнезия → староста → квест), ранний «вин» (волки → 150 монет).
- *Провисает:* **туториала нет вообще** (управление/механики не объясняются). Крючок-цель не подан как «дойти до…/узнать, что в зоне…». Игрок без подсказок управления может потеряться — риск на первой минуте.

**3. Петли удержания.**
- *Есть:* сохранения (костёр-автосейв), цель на сессию (квест), прогресс через снаряжение (частично).
- *Провисает:* **ежедневки/стрика нет, мета-прогресса между заходами (база/постройки/открытия) нет, отложенных крафтов нет.** Причины вернуться завтра по сути нет — **прямой удар по гейтам D1/D7**.

**4. Сюжетный спин.**
- *Есть:* сильный сеттинг (2039, постапок, аномалии, сталкер-тон), амнезия + **ноутбук бандитов = крючок «кто охотится за ГГ»**, квесты задают направление; подача через NPC-диалог (работает).
- *Провисает:* эпизодических квестов **2, нужно 3–5**; сквозная цель пока в зачатке.

**5. Монетизация встроенная.**
- *Есть:* **ничего** (ни RuStore Pay SDK, ни рекламного плагина, ни IAP — проверено грепом). Только направление в GDD.
- *Делать с нуля.* Предложения — в п.5 ниже.

**6. Оптимизация под слабый Android.**
- *Есть:* решения заранее (без Lumen/Nanite, vertex-color без текстур, низкополи, план Foliage/HISM — `mobile-optimization.md`).
- *Провисает:* **Android ни разу не паковался; FPS, вес APK, мин-устройство не замерены.** Главный технический риск Unreal на слабых.

**7. LiveOps/события.**
- *Есть:* расширяемый каркас квестов (Kill/Collect/Deliver).
- *Провисает:* DataTable (квесты/предметы) **не сделан** (этап E); системы временных событий нет; скорость добавления контента не замерена. In-app Events RuStore потребуют отдельной механики.

## B. Ответы на 11 вопросов

**1. Готовность.** Осталось: C (реорг карты, идёт), D (визуал+звук оружия, радиусный удар холодного), E (DataTable), F (весь UI на UMG), G (Android+оптимизация). **Блокеры:** навмеш не пересчитан на новой карте → враги не спавнятся в ней; весь UI на коде (не UMG). **Срок 70→100: достоверно не оценю** — дат нет, скорость не замерена. И: под удержание/монетизацию появляется НОВЫЙ объём (онбординг, ежедневки, мета-прогресс, «сочность», RuStore/реклама), которого в текущих 30% нет.

**2. Core loop 5/30 мин.**
- *5 мин:* квест у старосты → дойти до логова (восток) → отстрелять волков → 3 шкуры → вернуться → 150 монет.
- *30 мин:* оба квеста (волки + база бандитов за ноутбук, 250) → траты у торговца (снаряжение/патроны/медикаменты) → контроль голода/жажды → возможные смерти со штрафом и возврат за «мешком».
- *Фан:* напряжение выживания + читаемый top-down бой + прогрессия через снаряжение (модель LDoE, без XP). ⚠️ **плейтестом не валидировано.**

**3. Референсы.** Last Day on Earth (главный, подтверждён Ринатом); S.T.A.L.K.E.R. (тон/сеттинг). Жанрово — survival-shooter с RPG; отличие от безликих survivors — сеттинг + нарратив.

**4. Удержание сейчас.** Туториал — **нет**. Ежедневка — **нет**. Прогресс между сессиями — только снаряжение (частично). Сохранения — **есть** (PIE-подтв.).

**5. Монетизация (план — предложение, экономики пока нет).**
- *Rewarded (как польза):* x2 награды за сданный квест; «второй шанс»/воскрешение на месте вместо штрафа смерти; x2 лута с зачищенной базы; ускорить будущий крафт; доп. попытка.
- *Покупки (перманент):* удаление рекламы; стартовые наборы снаряжения; премиум-валюта; косметика/скины брони (**модульность уже в архитектуре → скины дёшевы**).
- *Экономика:* сейчас только черновые цены на тюнинг (старт 50 монет, патрон 2, пистолет 150, броня 60–120). **F2P-экономику с премиум-валютой и защитой от слома рекламой/покупками надо проектировать с нуля.**

**6. Контент-пайплайн.** Скорость «в неделю» **не отслеживается**. Факт демо: 2 квеста, 2 оружия, 2 врага, 1 локация (3 энкаунтера). После DataTable (E) добавление квестов/предметов ускорится.

**7. Техника.** Unreal **5.5.4**. Вес APK — **не замерен**. Мин-устройство — **не определено**. FPS на слабых — **не замерен** (Android не паковался).

**8. Арт.** Стиль: лоуполи, vertex-color, палитра утв., 4 стиль-арта. Ассеты — препродакшн/плейсхолдеры (финал-арт-пасс в конце, ADR-020). **Кадры для скринов/роликов сейчас — пока нет** (карта в реорге, навмеш/свет не добиты). Стиль-арты для питча — можно.

**9. Команда.** ИИ-агенты под управлением Рината: game-lead (оркестратор) + C++, оператор Unreal, 3D-моделлер, концепт-художник, QA (далее +game-designer/tech-artist/sound/level/ui-ux). Инструменты: UE 5.5, Blender, git+LFS, нативный code-render. Недельная ёмкость — **не замерена**. «Подключать ли ИИ-инструменты» — **они и есть основа пайплайна**. Как подать издателю — решение Рината.

**10. Маркетинг-материалы.** Трейлер — **нет**. Key-art (продакшн) — **нет** (4 AI-стиль-референса). Соцсети — **нет**. Черновик страницы стора — **нет**. Есть: 12 HUD-иконок, схемы карты/деревни, палитра, макет попапа смерти.

**11. Топ-3 риска.**
1. **Удержание не спроектировано** — нет туториала/ежедневок/мета-прогресса/«сочности». Под гейты D1≥35%/D7≥10% — главный риск (без них лить трафик бессмысленно).
2. **Android-производительность непроверена** — вес APK и FPS на слабых не замерены; классический риск Unreal-мобайла.
3. **Монетизация и интеграции с нуля** — RuStore Pay SDK, VK Ads/myTarget, F2P-экономика; в проекте сейчас 0.
