# Мобильная оптимизация ContrarySurvivor (план на ЭТАП ОПТИМИЗАЦИИ)

> Утверждено Ринатом 2026-06-16. Делать на отдельном этапе оптимизации (не сейчас).
> Цель платформы: ПК + Android (слабые устройства). iOS отложен.
> ВАЖНО: Lumen и Nanite — НЕ брать (Lumen = дорогое динамич. освещение, не для телефона; Nanite не поддержан на слабых Android).

## Трава / листва (главная нагрузка)
- **Foliage / HISM** (Hierarchical Instanced Static Mesh) вместо обычного ISM — авто per-instance culling + LOD, один draw-call на тип меша. Главный инструмент. Сейчас трава = ISM (GrassField), перевести на Foliage/HISM.
- **Cull Distance + per-instance fade** — трава рисуется только рядом с игроком, дальше отсекается/растворяется (Cull Distance Volume / настройки instance).
- **LOD у меша травы** — дальше упрощённый меш / билборд.
- **Scalability по устройству** — на слабых устройствах меньше инстансов травы (foliage density scaling / scalability settings).

## Уровень / стриминг
- **World Partition** — УЖЕ принято (один большой уровень стримится по ячейкам). 
- **HLOD** — прокси-меши для дальних ячеек WP (меньше нагрузка на дальнем плане).

## Освещение / рендер
- **Статичный/запечённый свет (Lightmaps)** — для телефона, дёшево.
- **Forward / Mobile renderer** — мобильный путь рендера.
- НЕ Lumen, НЕ Nanite (см. выше).

## Итог для нашей травы (первый шаг этапа оптимизации)
ISM → **Foliage/HISM + Cull Distance + LOD**, свет держать запечённым, плотность масштабировать по устройству.

(Источник: общая практика UE для мобайла; перед применением сверить точные настройки по доке UE 5.5.)
