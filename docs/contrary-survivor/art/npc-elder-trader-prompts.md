# Промпты для нейронки-генератора — внешний вид NPC: Староста и Торговец

**Дата:** 2026-07-09 · **Автор:** concept-artist (через game-lead) · **Статус:** ЧЕРНОВИК — на прогон Ринатом через внешний генератор изображений (своего генератора у команды нет, ADR-004). Картинки-референсы → отбор Рината → по отобранным лепит `modeler-3d`.

**Задача (решение Рината, 2026-07-07):** внешний вид старосты и торговца — по 2 комплекта одежды (голова/торс/ноги) на каждого = 4 блока промптов, RU+EN.

**Источники:** GDD ч.3 (сеттинг: русский постапок 2039, быт — да) и ч.4 (староста — квесты, торговец — магазин; модульность ADR-018: 3 слота Head/Torso/Legs на общем скелете); спек `npc-humanoid-spec.draft.md` (принцип читаемости: староста = тёплый земляной доминант, торговец = холодный серый + малый янтарный акцент-«маркер магазина»); арт-дирекшн экипировки `armor-wearables-artdirection.md` (утв. 07-06: низкополи, флэт-цвета, гамма муторно-землистая, всё ношеное).

**⛔ Красная линия (ADR-040), зашита в каждый промпт:** никакой военной формы и камуфляжа, госсимволики/флагов/шевронов, религиозной атрибутики, политики; без карикатурной «советскости» (не ватник/ушанка/кирза).

**Общие требования (входят в каждый промпт):** персонаж в полный рост; 3 ракурса (строго спереди / строго сбоку / строго сзади) на одном листе, один масштаб; нейтральная стоячая A-поза (T-поза допустима); чистый однотонный светло-серый фон; силуэт и цветовые пятна читаются сверху (top-down камера); одежда явно членится на 3 модуля — голова(убор) / верх до линии бёдер / штаны с обувью — с чистой границей на поясе; стиль низкополи, плоские цвета без текстурных деталей.

## Принцип читаемости пары (из спека `npc-humanoid-spec.draft.md` §5–6)
- **Староста = тёплый земляной**, торговец = **холодный серый + янтарная точка** — с top-down камеры двое дружественных NPC не путаются ни между собой, ни с врагами (яркий ржавый `#C64B2C` остаётся маркером врагов и в этих комплектах не используется).
- Головные уборы четырёх комплектов дают четыре разных купола сверху: седая голова / круглая шапка / плоская бандана / кепка с козырьком.

## Допущения (явно)
- Конкретная одежда старосты и торговца в GDD не задана — комплекты выше выведены из спека `npc-humanoid-spec.draft.md` (§5–6, вопросы §8 Ринатом не отвечены) и утверждённой арт-дирекшн экипировки. Отбор — за Ринатом по сгенерированным референсам; открытые вопросы спека §8 (акцент, разведение по цвету, головные уборы) закрываются этим отбором.
- Пропы (посох старосты / короб товара торговца) в промпты НЕ включены — вопрос §8.5 спека открыт, промпты покрывают только одежду по 3 слотам.
