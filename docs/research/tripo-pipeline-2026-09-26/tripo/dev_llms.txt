# Tripo3D API Documentation

> Tripo3D is an AI-powered 3D generation platform providing text-to-3D, image-to-3D, rigging, mesh editing, and format conversion APIs.
> Documentation is available in English (/en/) and Chinese (/zh/).

## Documentation Pages

- [Introduction](/en/docs/introduction): Overview of the Tripo API, base URLs, authentication, and response format.
- [Quick Start](/en/docs/quick-start): Get started with your first API call in minutes.
- [Authentication](/en/docs/authentication): API key management and Bearer token authentication.
- [Changelog](/en/docs/changelog): API version history and breaking changes.
- [SDK Integration](/en/docs/sdk): Locked JavaScript V3, Python V2, Go V3, Rust V3, and Java V3 sources, installation, complete first calls, downloads, and route support.
- [ComfyUI Nodes](/en/docs/comfyui-nodes): Independent reference for the 11 nodes in ComfyUI-Tripo 1.3.0, including installation, inputs, outputs, workflows, and troubleshooting.
- [Codex Plugin](/en/docs/codex-plugin): Beginner walkthrough for generating 3D models in Codex with the Tripo 3D plugin.
