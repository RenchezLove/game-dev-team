# Mesh Part Completion
**Base URL:** `https://openapi.tripo3d.ai/v3`
**Endpoint:** `POST /mesh/complete`
Complete segmented mesh parts and repair missing regions.
## Request Parameters
### input
- **Type:** string
- **Required:** Required
task_id of a `mesh/segment` task, starting with `task_`.
### model
- **Type:** string
- **Required:** Optional
- **Default:** `v1.0-20250506`
Completion model version.
- `v1.0-20250506` â default (current only version).
### part_names
- **Type:** string[]
- **Required:** Optional
List of part names to complete. If omitted, all parts are completed.
### completion_mode
- **Type:** string
- **Required:** Optional
- **Default:** `ai_completion`
Completion mode.
- `ai_completion` â AI diffusion-based completion (default). Generates realistic geometry to fill missing regions.
- `quick_cap` â Quick hole-fill. Fast sealing of open boundaries without AI generation.
## Request Example
### Complete (AI)
```bash
curl --request POST \
  --url https://openapi.tripo3d.ai/v3/mesh/complete \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
  "input": "task_abc123",
  "part_names": [
    "head",
    "body"
  ]
}'
```
### Quick Cap
```bash
curl --request POST \
  --url https://openapi.tripo3d.ai/v3/mesh/complete \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
  "input": "task_abc123",
  "completion_mode": "quick_cap"
}'
```
