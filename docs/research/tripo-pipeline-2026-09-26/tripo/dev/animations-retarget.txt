# Animation Retargeting
**Base URL:** `https://openapi.tripo3d.ai/v3`
**Endpoint:** `POST /animations/retarget`
Apply a preset animation to a rigged 3D model.
## Request Parameters
### input
- **Type:** string
- **Required:** Required
task_id of the rigged model, starting with `task_`.
### animation
- **Type:** string
- **Required:** Conditional
Single preset animation identifier.**Mutually exclusive with `animations` â provide only one.**
Rig v2.5-20260210 â All rig types
- Biped: `preset:idle`, `preset:walk`, `preset:run`, `preset:dive`, `preset:climb`, `preset:jump`, `preset:slash`, `preset:shoot`, `preset:hurt`, `preset:fall`, `preset:turn`
- Quadruped: `preset:quadruped:walk`
- Others: `preset:hexapod:walk`, `preset:octopod:walk`, `preset:serpentine:march`, `preset:aquatic:march`

### animations
- **Type:** string[]
- **Required:** Conditional
List of multiple preset animation identifiers.**Mutually exclusive with `animation` â provide only one.**
### out_format
- **Type:** string
- **Required:** Optional
- **Default:** `glb`
Output format.
- `glb` â binary glTF, web-ready.
- `fbx` â FBX for DCC tools and game engines.
### bake_animation
- **Type:** boolean
- **Required:** Optional
- **Default:** `true`
Bake animation into the model. Only effective for `glb` output.
### export_with_geometry
- **Type:** boolean
- **Required:** Optional
- **Default:** `true`
Export with geometry included.
### animate_in_place
- **Type:** boolean
- **Required:** Optional
- **Default:** `false`
Play animation in place without displacement.
## Request Example
### Single
```bash
curl --request POST \
  --url https://openapi.tripo3d.ai/v3/animations/retarget \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
  "input": "task_abc123",
  "animation": "preset:walk",
  "out_format": "glb",
  "bake_animation": true
}'
```
### Batch
```bash
curl --request POST \
  --url https://openapi.tripo3d.ai/v3/animations/retarget \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
  "input": "task_abc123",
  "animations": [
    "preset:idle",
    "preset:walk",
    "preset:run"
  ],
  "out_format": "fbx"
}'
```
