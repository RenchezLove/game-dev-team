# Моя команда — окно управления командой разработки

Личная оболочка над установленным Claude Code. Сторонних пакетов нет, нужен только Node.js.

- **Запуск:** ярлык «Моя команда» на рабочем столе или `start.cmd`. Он поднимает служебный сервер (если тот ещё не запущен) и открывает окно в Edge. Сервер слушает только `127.0.0.1:47821`, из сети не виден.
- **Чат:** сообщение уходит руководителю команды (`claude -p` с агентом проекта) на подписке владельца. Картинки — перетаскиванием или Ctrl+V. Запросы на разрешение действий приходят в окно кнопками «Разрешить» и «Отклонить».
- **Задачи:** файл `<папка команды>/tasks/<проект>.json`; состояние «на телефоне / в магазине / автопроверки» — `<проект>-status.json` рядом. Руководитель ведёт оба файла сам.
- **Документы:** папки из `data/projects.json`; править в окне можно `.md` и `.txt` (прежняя версия копируется в `data/backup-*`).
- **Банк ассетов:** список собирается проходом по папке содержимого игры, вид определяется по началу имени файла.
- **Проверка чата:** `node chat-selfcheck.js <пустая папка> <файл вне её>`.

Схемы и заметки: `docs/team-app/`.
- **Голос:** кнопка «🎙 Голосом» в карточке чата — живой разговор с голосовой моделью OpenAI (`voice.js` на сервере и `public/voice.js` на странице). Ключ OpenAI остаётся на сервере, странице выдаётся пропуск на 2 минуты. Помощник сам отправляет руководителю задание (`send_task`), узнаёт состояние (`get_status`), останавливает работу с подтверждения (`stop_task`) и сам сообщает, когда руководитель закончил. Модель, голос и дневной предел расходов (по умолчанию $3) — `data/voice-settings.json` (`model`, `voice`, `dailyUsd`); расходы — `data/voice-usage.json`, запись разговора — `data/voice-<проект>.json`.
