## Решения
- Health: игрок И враги — через `UStatsComponent` (TakeDamage БЕЗ Super). `HandleDeath()` virtual; `ReloadCurrentWeapon` virtual (патроны из рюкзака, AAmmoItem-стак).
- `GetMesh()==HeadMesh==Leader` модульного гуманоида; Torso/Legs — followers (SetLeaderPoseComponent). Оружие к кости `R_Hand`, офсеты — параметры.
- Волк — НЕ гуманоид: ACharacter + SK_Wolf + Single Node анимации; ИИ = AWolfAIController(AEnemyAIController).
- **SetFocus сам пешку НЕ вращает** (UE 5.5 Pawn.cpp:1049) — доворот наш StartAimTurnTo.
- ИИ погони: состояния Idle/Chase/Attack, навигация с прямым запасным путём; отладочный лог дросселирован.
- **Игровой слот сохранения один (`ContrarySave`), поля удержания в нём же:** `SaveGame()` игрока создаёт свежий объект → ПЕРЕНОСИТ поля удержания из прежнего сейва (`UContrarySaveGame::CopyRetentionData`). Компоненты удержания правят ТОЛЬКО свои поля через `LoadOrCreateSaveObject`/`WriteSaveObject`. Отдельно от него — служебный слот аналитики `ContraryAnalytics` (см. СЕЙЧАС), он переживает «Новую игру».
- Чистая логика серии ежедневных входов — `Retention/DailyRewardLogic.h` (без UObject) — гоняется автотестом без редактора.
- **АРХИТЕКТУРНОЕ РЕШЕНИЕ (моя поправка к решению лида):** переводимое имя предмета живёт НА ЭКЗЕМПЛЯРЕ (`AMasterInventoryItem::ItemDisplayText` + `GetItemDisplayText()` с откатом название→ключ→заглушка), а НЕ на классе: один класс обслуживает разные предметы (`AQuestItem` — и шкура, и ноутбук; `AConsumableItem` — вода/консервы/бинт).
- **⛔ КЛЮЧИ, КОТОРЫЕ НЕЛЬЗЯ ПЕРЕВОДИТЬ (сломает квест):** `AMasterInventoryItem::ItemName`, `FQuest::RequiredItemName`, `FQuest::KillTargetTag`, значения в `ElderNPC.cpp` («Шкура волка», «Ноутбук»), сравнение `QuestComponent.cpp:204,252`.
- **ПАТТЕРН ЛОКАЛИЗАЦИИ (эталон — `UI/PlayerStatsWidget.h`):** `UPROPERTY(EditAnywhere, BlueprintReadWrite) FText` с дефолтом `NSLOCTEXT` ПРЯМО В ЗАГОЛОВКЕ (UHT запрещает LOCTEXT в дефолтах свойств); сборка строки — `FFormatNamedArguments` + `FText::Format`; числа — `FText::AsNumber(FMath::RoundToInt32(...))`. Ловушка `FText::FromString` на потребителе обнуляет перевод.
- **Архитектура ADR-048:** C++ UUserWidget-классы с кубиками `BindWidgetOptional` (пусто → предупреждение, не падение); раскладку WBP строит РИНАТ мышкой; в HUD слоты TSubclassOf: слот пуст → работает старый Canvas-путь, назначен → UMG. Canvas-код панелей НЕ удалять. Модальные окна Z=30, экран смерти Z=35, постоянные панели Z=5.
- **ЛОВУШКА СКРЫТИЯ:** если код прячет кубик со значением, а подпись лежит рядом в дизайнере — подпись остаётся висеть. Решение: привязывать КОНТЕЙНЕР и прятать его (`AmmoRow`).
- **Живой признак платформы (не выдумывать свой):** `AContrarySurvivorPlayerController::HasTouchLayer()` (`.h:115`), под ним `#if PLATFORM_ANDROID`. Отвечает «показан ли слой экранных кнопок», а не «телефон ли это».
- **Android-тапы:** тап НЕ порождает клик мыши для игрового ввода — порождает Touch1..Touch3 (`PlayerInput.cpp:473`). Легаси-действие `ScreenTap` → тот же `Fire()`; позиция тапа = кеш курсора вьюпорта. UMG от пальца работает штатно (`bTouchFallbackToMouse`). `DefaultTouchInterface=None` в DefaultInput.ini.
- **Генератор панелей** `Source/ContrarySurvivorEditor/GenerateWbpCommandlet.cpp` — за мной, но сейчас его правит сосед. Перегенерация только по сигналу лида: с ключом `-force` затрёт стилизацию Рината.
