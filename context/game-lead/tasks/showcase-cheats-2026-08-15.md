## Команды (все — Exec в cheat-manager; имена ровно такие)
1. `QAWatch` — НЕ команда, а автозапуск: если в командной строке есть `-ShowcaseWatch` (`FParse::Param(FCommandLine::Get(), TEXT("ShowcaseWatch"))`), cheat-manager при создании (`InitCheatManager`) запускает опрос папки `<Project>/Saved/Showcase/inbox/` раз в 0.5 с через `FTSTicker::GetCoreTicker()` (реальное время, работает и на паузе). Первый по имени файл `*.txt` → переименовать в `*.running` → выполнить построчно → переименовать в `*.done`. Тикер снять в `BeginDestroy`.
   Формат скрипта: пустые строки и строки с `#` пропускаются; `wait <сек>` (дробное) — пауза реального времени; любая другая строка — консольная команда через `GetOuterAPlayerController()->ConsoleCommand(Line, true)`. Лог: `QA: SCRIPT start <файл>`, `QA: SCRIPT line <n>: <текст>`, `QA: SCRIPT done <файл>`.
2. `QARunScript <имя>` — то же вручную: выполнить `<Project>/Saved/Showcase/<имя>.txt`.
3. `QAShot <имя>` — снимок игровой области с интерфейсом в `<ShotDir>/<имя>.png` (ShotDir по умолчанию `<Project>/Saved/Showcase/out/`, папку создать). Лог: `QA: SHOT saved <путь> (WxH)` / `QA: SHOT FAILED <путь>`. `QAShotDir <путь без пробелов>` — сменить папку.
4. `QATeleport X Y Z [Yaw]` — телепорт персонажа игрока (остановить движение; `TeleportPhysics`). Лог с новой позицией. `QAWhere` — в лог позиция+поворот игрока и позиция/поворот/FOV текущей камеры.
5. `QADumpActors <подстрока>` — в лог все акторы, у которых имя класса ИЛИ имя/метка (в -game метки могут отсутствовать — fallback GetName) содержит подстроку без учёта регистра: `класс | имя | X Y Z | Yaw`. Нужно, чтобы найти логово волков, старосту, торговца, костёр, PlayerStart, точки интереса.
6. `QASpawnWolf X Y Z Yaw [Pose] [Phase]` — заспавнить волка (тот же класс, что в игре — найди, откуда спавнит `AWanderingWolfSpawner`/логово) в точке с поворотом и СРАЗУ обездвижить: мозги не тикают (не бегает, не кусает, не аггрится, не поворачивается к игроку), ноги стоят, и он НЕ регистрируется как обычный враг для квестов/счётчиков, если это возможно без правки геймплея (если невозможно — скажи прямо). Pose: `idle` | `run` | `attack` | `dead`; Phase 0..1 — доля анимации, на которой замереть (по умолчанию 0.5). Как заморозить позу — разберись по реальной анимационной схеме волка (AnimBP/монтажи в Content/Characters или где он лежит; проверь через файлы `.uasset` имена и логику через `Source/`); ожидаемый рабочий путь: запустить нужную анимацию/монтаж, а затем `CustomTimeDilation = 0` на акторе (анимация и движение встают на месте; компоненты тикают с дилатацией актора). Если для `run`/`attack` управлять AnimBP из C++ нечем — реализуй `idle` и `dead` честно и напиши, чем ограничен. Каждый заспавненный — в список; лог `QA: WOLF spawned #<n> at …`.
7. `QAClearWolves` — убрать всех заспавненных этой командой волков. `QAFreezeEnemies 0|1` — явная версия U (не тумблер). `QAGod 0|1` — явная версия T.
8. `QAPlayerFace Yaw` — развернуть игрока лицом по азимуту и удерживать позу прицеливания, если такая есть в анимации; `QAFire` — один выстрел из текущего оружия тем же путём, что тап/ЛКМ (вспышка+звук+отдача как в игре). `QAEquipPistol`/выдача оружия — если оружие у игрока не с самого начала, дай команду выдать пистолет (посмотри, что делают старые тест-команды выдачи предметов в git-истории: `git log -S"TestItems" --oneline`, они удалены 15.08 в `3409c26`).
9. `QAGiveShowcaseLoot` — надеть на игрока полный доступный комплект брони (голова/тело/штаны — какие тиры есть) и набить рюкзак разнообразными предметами (еда, вода, патроны, шкуры, ресурсы — всё, что есть в игре, по 1–2 стака каждого, чтобы окно инвентаря выглядело полным). Найди реальные определения предметов (DataTable/DataAsset/классы) и используй их. `QAGiveMoney <N>` — выдать N денег (по умолчанию 500).
10. `QAOpenInventory` / `QAOpenShop` / `QACloseUI` — открыть окно инвентаря; открыть окно торговца с ближайшим (или единственным) торговцем через тот же `OpenShop(...)`, что в игре (игрок может быть далеко — это допустимо, снимок нужен, а не честность); закрыть открытые окна.
11. `QAFullStats` — явная версия Y. `QAEndIntro` — завершить интро немедленно (если игра стартует с интро). `QAHideHUD 0|1` — спрятать/показать игровой UMG-интерфейс (полосы, кнопки, задание) целиком.
12. Камера: `QACamZoom <длина_штанги> [pitch]` — если камера игрока на SpringArm/смещении, поменять дистанцию (и наклон, если он задаётся числом), `QACamReset` — вернуть. `QADebugCam X Y Z Pitch Yaw [FOV]` — включить свободную камеру F1 (если ещё нет) и поставить её ровно сюда; `QADebugCamOff` — выйти.
