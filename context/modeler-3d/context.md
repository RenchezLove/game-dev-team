- **🔑 ПЕРЕКРАСКА ЧУЖОГО FBX БЕЗ ДРЕЙФА:** в файле лежит `linear = s2l(sRGB)`, при импорте это сырое число попадает в `.color_srgb`. Для показа задуманного цвета реимпортированного меша — скопировать `.color_srgb` в `.color`.
- **🔑 Деревья/ветер:** `M_WindTrees` = маска по высоте (LocalPosition/ObjectLocalBounds), от меша нужны пивот в основании и zmin=0; BLEND_Opaque без текстур → листва только объёмом, vcol целиком в базовый цвет.

- **🔑 КОНВЕНЦИЯ ЦВЕТА FBX:** vcol экспорт ТОЛЬКО `colors_type='LINEAR'` (зашит в `wcommon.export_skeletal`); умолчание 'SRGB' → двойное кодирование в UE → тёмно-серо. vcol пишем `color_srgb` = sRGB-хекс палитры напрямую; в FBX ложится linear-пересчёт — это норма. Судить о цвете в UE — ТОЛЬКО по UE (PIE/Geometry Script), Blender-ре-импорт FBX — ложный слепок (урок 07-09). - **🔑 УРОК ×100:** арматура из UE-FBX приходит ребёнком EMPTY (scale 0.01) базис 100; `transform_apply` печёт только базис → кости ×100, в покое невидимо, при позе меши взрываются. Печь ПОЛНУЮ matrix_world в edit-кости (`wcommon.apply_armature_transform`). Позовый прогон ОБЯЗАТЕЛЕН перед сдачей.
- **🔑 УРОК weld:** UE-меши развёрнуты по вершинам (verts≈3×tris) — перед островным анализом `remove_doubles` 1e-4 (веса/vcol переживают). Headless-скрипт может упасть Traceback при EXIT=0 — всегда grep Traceback в логе.
