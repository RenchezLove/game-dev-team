## Постоянные директивы (не трогать без причины)
- **Инструмент (ADR-021):** headless CLI `E:/Programs/Blender/blender.exe -b [файл.blend] --factory-startup --python <скрипт> -- <args>` (Blender 5.1.2). MCP `mcp__blender__*` в субагенте НЕ инжектится. Лог — в файл. Bash без Python; PowerShell-кириллица капризна.
- **Конвенции:** метры, FBX uniform scale 1 (UE ×100), FBX7400 MESH-only, vcol 'Col' CORNER/BYTE, 1 мат/ассет (минимум слотов — Android), flat shade, нормали наружу (recalc + signed_volume>0), Smart-UV 0-1. Пропсы: forward +Y, origin центр основания Z=0. Оружие: forward +X, origin рукоять. Гуманоиды: forward −Y.
- **Каталог (ADR-022):** `assets/<id>/` = паспорт `<id>.asset.md` (цифры ТОЛЬКО из round-trip) + превью + рендеры. Бленды пер-ассет НЕ копируем — источник правды = билдер + QC-бленд в `_build/`.
- **Правило сдачи:** приёмка визуально game-lead по PNG → потом финал-экспорт + round-trip + пруф файла на диске. «Экспортировано/готово» — только после проверки файла.
- **🔑 Цвет (двойное затемнение):** lin() темнит палитру (BYTE_COLOR читает linear как sRGB). Для точного/светлого тона — писать СЫРОЙ sRGB как linear (машина/палатка так и сделаны) или attr.color напрямую. Судить о цвете FBX по РЕНДЕРУ, не по дампу.
- **UE-памятка:** импорт Vertex Color = Replace; материал VertexColor('Col')→BaseColor; тонкое (ткань/трава/лезвия) — Two-Sided.
- **Blender-сокет одноклиентный** — не спавнить двух modeler к Blender параллельно.
