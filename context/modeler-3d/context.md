## Постоянные директивы (не трогать без причины)
- **🔑 АНИМАЦИИ ГУМАНОИДА:** авторить ТОЛЬКО мировыми направлениями (`anim_humanoid/_work/acommon.py`: aim_world/rot_world/Keyer со знаково-непрерывными кватернионами) — имена правой руки сдвинуты на сустав (`R_Arm`=плечо, предплечье=`Pelvis_009_R_002`); предел угла ключица↔плечо 110° (дальше дельта расплывается, чек в билдере); экспорт БЕЗ мешей, add_leaf_bones=False, simplify 0.0, действие через временную NLA-полосу; верхнетелесные — ключи только на 12 костях верха; длину такта проверять В КОНТЕЙНЕРЕ FBX (Takes/LocalTime), сцена после реимпорта врёт 1..250; эталон осей: 7400, Up=Y, Front=Z, Coord=X, UnitScale 1.0, 30 к/с.
- **🔑 ПЕРЕКРАСКА ЧУЖОГО FBX БЕЗ ДРЕЙФА:** в файле лежит `linear = s2l(sRGB)`, при импорте это сырое число попадает в `.color_srgb`. Нетронутое — `.color = сырое`, перекрашенное — `.color_srgb = задуманный sRGB` (или сырым в тех же байтах, как исходник писал), экспорт в кодировке исходника. Для показа задуманного цвета реимпортированного меша — скопировать `.color_srgb` в `.color`.
- **🔑 Деревья/ветер:** `M_WindTrees` = маска по высоте (LocalPosition/ObjectLocalBounds), от меша нужны пивот в основании и zmin=0; BLEND_Opaque без текстур → листва только объёмом, vcol целиком в базовый цвет.
- **Игровая камера (факт из `PlayerCharacter.h`):** перспектива, pitch −60°, дистанция 30 м, FOV 40° → ширина кадра ≈21.8 м. В Blender: камера на `цель + 30·(0, cos60, sin60)`, `sensor_fit='HORIZONTAL'`, `angle_x=40°`.
- **Инструмент (ADR-021):** headless CLI `E:/Programs/Blender/blender.exe -b [файл.blend] --factory-startup --python <скрипт> -- <args>` (Blender 5.1.2). MCP `mcp__blender__*` в субагенте НЕ инжектится. Лог — в файл. Bash без Python; PowerShell-кириллица капризна.
- **Конвенции:** метры, FBX uniform scale 1 (UE ×100), FBX7400 MESH-only, vcol 'Col' CORNER/BYTE, 1 мат/ассет (минимум слотов — Android), flat shade, нормали наружу (recalc + signed_volume>0), Smart-UV 0-1. Пропсы: forward +Y, origin центр основания Z=0. Оружие: forward +X, origin рукоять. Гуманоиды: forward −Y.
- **Каталог (ADR-022):** `assets/<id>/` = паспорт `<id>.asset.md` (цифры ТОЛЬКО из round-trip) + превью + рендеры. Бленды пер-ассет НЕ копируем — источник правды = билдер + QC-бленд в `_work/`.
- **Правило сдачи:** приёмка визуально game-lead по PNG → потом финал-экспорт + round-trip + пруф файла на диске. «Экспортировано/готово» — только после проверки файла.
- **🔑 Пайплайн NPC = пайплайн экипировки:** `10_build_*.py` (детерминированный из `armor_wearables/_work/master.blend`) → `11_pose_check_*.py` → `12_export_verify_*.py`; хелперы `armor_wearables/wcommon.py`. Схема: dup базы (BaseHead/L1_Torso/L1_Legs) → weld 1e-4 → перекраска зон vcol → навесная геометрия bmesh → перенос весов KDTree → finalize → export LINEAR. Трюк «тело под одеждой красить цветом одежды» убирает просветы. У старосты `drop_front_boxes` удалял 4 коробки торса; у торговца они ОСТАВЛЕНЫ как подсумки — выбор зависит от костюма.
- **🔑 КОНВЕНЦИЯ ЦВЕТА FBX:** vcol экспорт ТОЛЬКО `colors_type='LINEAR'` (зашит в `wcommon.export_skeletal`); умолчание 'SRGB' → двойное кодирование в UE → тёмно-серо. vcol пишем `color_srgb` = sRGB-хекс палитры напрямую; в FBX ложится linear-пересчёт — это норма. Судить о цвете в UE — ТОЛЬКО по UE (PIE/Geometry Script), Blender-ре-импорт FBX — ложный слепок (урок 07-09). О тёплых/светлых тонах — по РЕНДЕРУ, не по хексу (урок седины: палитровый `#9AA08C` холодит, брали `#ADA492`).
- **🔑 УРОК ×100:** арматура из UE-FBX приходит ребёнком EMPTY (scale 0.01) базис 100; `transform_apply` печёт только базис → кости ×100, в покое невидимо, при позе меши взрываются. Печь ПОЛНУЮ matrix_world в edit-кости (`wcommon.apply_armature_transform`). Позовый прогон ОБЯЗАТЕЛЕН перед сдачей.
- **🔑 УРОК weld:** UE-меши развёрнуты по вершинам (verts≈3×tris) — перед островным анализом `remove_doubles` 1e-4 (веса/vcol переживают). Headless-скрипт может упасть Traceback при EXIT=0 — всегда grep Traceback в логе.
- **UE-памятка:** импорт Vertex Color = Replace; материал слота в FBX — заглушка, в UE вешать рабочий `M_VColor` (М_*_Flat не компилился, прецедент 07-09); тонкое (ткань/хвосты/лезвия) — Two-Sided.
- **Blender-сокет одноклиентный** — не спавнить двух modeler к Blender параллельно.
