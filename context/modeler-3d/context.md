## ЧЕК-ЛИСТ повторяющихся дефектов (сверять ПЕРЕД каждым QC-рендером — наказ Рината)
- [ ] **Пропорции:** в профиль НЕ «бумажно-плоский». Торс/ноги/предметы — реальная глубина по Y (не один слой полигонов). Силуэт читается с 3 ракурсов.
- [ ] **Шея** есть (голова не «сидит» прямо на торсе без шеи).
- [ ] **Обувь** объёмная (не плоская подошва-лист).
- [ ] **Кепка/шапка/каска:** ЗАКРЫТАЯ тулья (купол на всю голову) + козырёк где нужно; не «нашлёпка».
- [ ] **vertex-color sRGB↔linear:** палитру задаю в sRGB hex, в vcol пишу через `D.lin()` (линейно). Записывать линейный эквивалент. QC view_transform='Standard'.
- [ ] **Узнаваемость формы** (наказ по костям): объект должен читаться как то, чем является (кость = череп+рёбра+эпифизы-набалдашники, НЕ палки).
- [ ] **Оси экспорта:** forward −Y, up +Z, rot 0, scale 1 (как вертикальные меши игрока/гуманоид). Пропсы origin низ-центр Z0.
- [ ] **import_uniform_scale=1** (НЕ 100 в Blender; UE сам 100x). FBX7400.
- [ ] **НЕТ контрового света в QC** (иначе силуэт примут за цвет). Харнесс `_qc_render.py` — свет camera-relative, без back-rim. Не менять.
- [ ] **ЦВЕТ В UE = ТОЛЬКО VERTEX-COLOR, НЕ материал-слоты** (наказ Этап-3). Наш FBX MESH-only (import_materials=False) → per-material цвета ТЕРЯЮТСЯ в UE (модель серая/однотонная). Один материал VertexColor('Col')→BaseColor. Пайплайн dcommon уже так делает (finalize пишет cm в 'Col', make_vcol_material = 1 vcol-материал) — НЕ красить регионы отдельными material-слотами. UE-импорт: «Vertex Color Import Option = Replace».
- [ ] **Все грани прокрашены** (нет magenta-fallback = незакрашенных).
- [ ] **Тонкая геометрия (трава/лезвия) → Two-Sided в UE** + проверить, что vcol реально в FBX (иначе чёрная).
- [ ] **Приёмку даёт game-lead визуально по PNG, не я.** Экспорт FBX — только после приёмки.

## Решения
- **Blender = v5.1** (build blender-v5.1-release, exe `E:\Programs\Blender\5.1`). API экспорта FBX сверял с живым RNA оператора, не по памяти. FBX-формат на экспорте = 7400.
- **Материал бандита = `M_Bandit_Flat`** — один материал на все 3 слота. Principled BSDF, Base Color из vertex-color атрибута `Col` (нода ShaderNodeVertexColor, layer "Col"). Metallic 0, Roughness 0.65, Specular 0.15. Без normal-map, baked-friendly (плоские регионы цвета + rust-акцент).
- **Палитра (hex):** skin C9A084, jacket 2B2B2E, tee 6E6E70, joggers 303033, sneaker ECECEC, cap 28282B, rust C64B2C. Vertex-color в линейном пространстве, домен CORNER (BYTE_COLOR).
- **Подход к одежде:** новые части (кепка, оболочка бомбера, лампас) строятся как добавленная геометрия и ДЖОЙНЯТСЯ в исходный слот-меш → 1 скинённый меш на слот. Веса новых вершин переносятся с ближайшей исходной вершины (KDTree) → корректная деформация. Проверено позой — clipping/отрыва нет.
