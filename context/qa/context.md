## Урок сессии: «EXIT=0» бывает пустым
`Build.bat` может вернуть 0 со строкой `Target is up to date`, не скомпилировав НИЧЕГО (например, мой запуск отстоял очередь на мьютексе за чужой сборкой). Для гейта это НЕ доказательство: искать в логе строки `Compile [x64] <нужный файл>`, нет их — гнать `Rebuild.bat`.

## Рецепты проверки
- **Мёртвая фича при зелёной сборке.** Пути на контент в C++ не проверяются компилятором. Выгрести все: `grep -rhoE '"/Game/[^"]+"' Source/` и каждый сверить с `Content/<путь>.uasset`. Дальше глубже: монтаж должен ссылаться на анимацию внутри, а метки (`AnimNotify_*`) реально лежать на дорожке — видно бинарным поиском по `.uasset`.
- **Правка комментария — тоже предмет проверки** (дважды ссылался на несуществующую сущность).
- **Удаление класса с UCLASS.** UHT сам чистит `Inc/.../UHT/`, но старые `.obj` остаются; доказательство невключения — файл ответа линковщика `UnrealEditor-<Модуль>.dll.rsp`.
- **Git LFS.** `git show HEAD:<ассет>` отдаёт указатель ~132 байта — норма; сверять `sha256sum` со строкой `oid sha256:`. Изменение видно как `git lfs status` → `LFS: <старый> -> File: <новый>`.
- **Двоичный поиск** только через Bash, всегда с позитивным и негативным контролем. Ловушка префиксов: `MI_FogBand` ловит `MI_FogBandSoft`.
- **Игнор в git** проверять `git status --porcelain --ignored` (`!!` против `??`) и `git add -n <путь>`, а не `check-ignore -v`.
- **Цепочки с grep рвутся:** ноль совпадений даёт код 1 и обрывает `&&`.

## Ограничения
- Вердикт только с реальными логами (правило B). Логи qa — в `context/qa/logs/`.
