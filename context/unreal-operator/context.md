## ⛔ Ловушки (каждая поймана живьём — не наступать снова)

- **Отрицательный результат требует положительного контроля.** Прежде чем сказать «ссылок нет», в тот же прогон проверяю тем же методом заведомо ЖИВОЙ ассет и убеждаюсь, что список ссылок непустой. Иначе не отличить «ссылок нет» от «метод молча вернул пусто». Так закрыта уборка 07-28: `M_FogSoft` показал двух потребителей, значит нули у мёртвых — настоящие.
- **Поиск имени ловит имя-надстройку.** `MI_FogBand` как подстрока сидит внутри живого `MI_FogBandSoft`, `M_FogWall` — внутри `M_FogWall2`. Голый поиск даёт ложную «живую ссылку» в карте и в BP. Разводить: `grep -rao 'ИМЯ.\{0,4\}' | sort | uniq -c` — видно, чем именно продолжается каждое вхождение.
- **Grep-тул по ПАПКЕ с бинарями врёт.** ripgrep бросает бинарный файл на первом NUL-байте и отвечает «No files found» (BP_WorldBorder.uasset не нашёл сам себя). Бинарный поиск по папке — ТОЛЬКО `grep -rla` через Bash. По одному явному файлу Grep-тул ищет честно.
- **Реестр ассетов НЕ видит загрузку строкой-путём из C++** (`ConstructorHelpers`/`LoadObject`): «0 референсеров» в реестре ≠ мёртвый ассет. Обязательно подтверждать грепом по `Source/` (искать и имя, и `/Game/...`-путь). Ловушка однажды сработала на `SM_Pistol`.
- **`get_all_level_actors` НЕ ВИДИТ transient-акторы.** Уборка по нему слепа. Полный список — `unreal.GameplayStatics.get_all_actors_of_class(world, unreal.Actor)` + фильтр по label/классу + контрольный повтор листинга. Transient-акторы GC не собирает.
- **`delete_asset` в населённой папке исторически НЕнадёжен** (возвращал True, а файл оставался). Всегда проверять `os.path.exists` внутри того же скрипта и `ls`/`git status` снаружи. 07-28 для трёх обычных материалов сработал честно: True и файла нет.
- **`get_referencers` СРАЗУ после операции в ТОМ ЖЕ процессе — устаревший.** Итоговую проверку делать в СВЕЖЕМ процессе после полного пересканирования.
- **In-memory ≠ диск.** Верификацию правки карты делать перезагрузкой (`load_map` заново после save), а не чтением того, что уже в памяти.
- **`set_collision_enabled()` на компоненте НЕ сериализуется** — на reload откат в дефолт из профиля. Записывается только `set_collision_profile_name("NoCollision"/"BlockAll")`.
- **Headless trace/sweep без PIE НЕВАЛИДЕН** — Chaos-сцена не инициализирована, возвращает канонический мусор (байт-в-байт одинаковый из разных точек). Коллизию проверять только в живом PIE.
- **`connect_material_expressions`: имя входного пина сопоставляется ПОСЛЕ сокращения** — «Input»→пустая строка, «Exponent»→«Exp», «Coordinates»→«UVs», «TextureObject»→«Tex», «MipLevel»→«Level», «MipBias»→«Bias»; A/B/Alpha/Base/Min/Max не сокращаются. При несовпадении connect ТИХО возвращает False → недосоединённый граф. Всегда проверять bool результата.
- **Материал-инстансы:** поле `InitialParent` у фабрики в Python не экспонировано — родителя задавать `MaterialEditingLibrary.set_material_instance_parent(mi, parent)` ПОСЛЕ `create_asset`. **Баг UE 5.5:** `set_material_instance_scalar_parameter_value` применяет значение, но ВСЕГДА возвращает False — bool игнорировать, проверять обратным чтением.
- **Перевод в редакторе намеренно НЕ применяется** (`ILocalizedTextSource.h`, `ShouldLoadNativeGameData` при `GIsEditor` отдаёт родной язык). Проверять локализацию только в режиме игры: `-game -culture=<язык> -nullrhi -unattended -ExecCmds="Localization.DumpLiveTable -Key=<ключ>, quit"`, обязательно два прогона плюс контрольная непереведённая строка.
- **Прочие квирки UE 5.5 Python:** у WidgetBlueprint `WidgetTree`/`RootWidget` protected (брать `unreal.find_object(None, "/Game/UI/WBP_X.WBP_X:WidgetTree.<Имя>")`, обход — `get_children_count()`/`get_child_at(i)`); `unreal.Rotator(roll, pitch, yaw)` — надёжнее задавать присваиванием полей; кириллица в ASCII-логе UE превращается в мохибейк, значение проверять обратным чтением; кириллица в `.ps1` ломает парсер Windows PowerShell — строки скриптов писать латиницей.
- **GUI-автоматизация: рабочий стол может быть занят живым Ринатом.** Обязательный предохранитель перед каждым вводом: `GetForegroundWindow` → процесс должен быть UnrealEditor, иначе прервать всё. Дважды спасло от клика в чужое окно. Случайные скрины чужих окон удалять.
