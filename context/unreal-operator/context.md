## Рабочие рецепты (проверены фактом, применяю постоянно)
- **Headless-прогон (ADR-021), штатный путь.** `MSYS_NO_PATHCONV=1 "E:/UnrealEngine/UE_5.5/Engine/Binaries/Win64/UnrealEditor-Cmd.exe" <uproject> -ExecutePythonScript="<abs.py>" -unattended -nopause -nosplash -abslog="<abs.log>"`. stdout пуст — печатать маркеры (`XXX|RESULT=OK`) и выдёргивать `grep -a`. Аргументы скрипту — внутри тех же кавычек → `sys.argv`. Редактор при этом закрыт (`tasklist`). ⛔ Exit code коммандлета НЕ доказательство — только маркер в логе.
- **Таблицы данных скриптом (проверено на DT_Items/DT_Quests 08-22).** Создание: `unreal.DataTableFactory()` + `set_editor_property("struct", unreal.load_object(None, "/Script/ContrarySurvivor.ContraryItemRow"))` + `create_asset`. Наполнение: `unreal.DataTableFunctionLibrary.fill_data_table_from_json_string(dt, json)` — JSON-список объектов с ключом `"Name"` = имя строки; **повторный вызов ЗАМЕНЯЕТ все строки целиком** (так делаются правки). FText в JSON — строкой-литералом `NSLOCTEXT("ns", "key", "текст")` (ключи/неймспейсы сохраняются в ассете — проверено grep по .uasset); мягкие ссылки — строкой пути `/Game/X.X` (класс — `..._C`), пустые — `"None"`; enum — именем значения. Проверка: `get_data_table_row_names`, `get_data_table_column_as_string` (FText печатает с NSLOCTEXT-обёрткой). ⚠ Один и тот же ключ перевода с РАЗНЫМ текстом (в C++ и в таблице) — конфликт сбора локализации: при смене текста брать НОВЫЙ ключ.
- **BP-ассеты скриптом (проверено 08-22, 11 штук).** `unreal.BlueprintFactory()` + `set_editor_property("parent_class", unreal.X)` + `create_asset(имя, папка, None, factory)` → `save_asset`. Дефолты: `load_object(None, ".../BP_X.BP_X_C")` → `get_default_object` → `set_editor_property` → `save_asset(only_if_is_dirty=False)` — переживают перезапуск, включая ТРАНСФОРМЫ нативных компонентов на CDO (`cdo.get_editor_property("WheelFL")` → `set_editor_property("relative_location", ...)`). ⚠ Питон-классы — ТИПЫ (`parent.get_name()` падает, писать `str(parent)`). ⚠ У AbandonedCar имена галочек и компонентов СОВПАДАЮТ в питон-именах (`bHood`и`Hood`→`hood`) — обращаться ТОЧНЫМИ C++-именами («bHood», «Hood»), возвращаемый объект проверять isinstance.
- **Съёмка headless через SceneCapture2D** (`create_render_target2d` + `SCS_FINAL_COLOR_LDR` + `capture_scene()` + `export_render_target`) — работает в коммандлете. ⚠ **Люмен в одиночном кадре захвата даёт шахматные артефакты на глянце** — в post_process_settings захвата выключать: `override_dynamic_global_illumination_method`/`override_reflection_method` = True, методы = NONE. ⚠ Размер PNG НЕ индикатор смены содержимого (детерминированный рендер даёт байт-в-байт равные длины при разном содержимом) — судить ТОЛЬКО глазами по кадру. ⚠ `unreal.AutomationLibrary.take_high_res_screenshot` в коммандлете асинхронный и может не дописаться до выхода — SceneCapture надёжнее.
- **Синхронная компиляция шейдеров на один запуск:** ключ `-ini:Engine:[DevOptions.Shaders]:bAllowAsynchronousShaderCompiling=False` (применение проверено по Command Line в логе). От битого кэша НЕ помогает — там лечит только `recompile_material` в сеансе.

## ⛔ Ловушки (каждая поймана живьём — не наступать снова)
- **После импорта скелетного меша проверять слоты материалов** (`WorldGridMaterial` = не назначился; положительный контроль — соседний живой ассет).
- **Меши экземпляра на карте перекрывают CDO класса** — проверять срезом экземпляра.
- **Сверять имена/пути ассетов С КОДОМ до создания** (grep по Source/), мягкая ссылка на несуществующее молча мертва — не ловится ни сборкой, ни тестами.
- **Отрицательный результат — только с положительным контролем тем же методом.**
- **Grep-тул по папке с бинарями врёт** (NUL-байт) — только `grep -rla` через Bash; поиск имени ловит имя-надстройку (`uniq -c` по продолжениям).
- **Реестр ассетов не видит загрузку строкой из C++** — «0 референсеров» ≠ мёртвый; грепать Source/.
- **`get_all_level_actors` не видит transient** — полный счёт `GameplayStatics.get_all_actors_of_class`.
- **Подобъект, созданный из питона, навсегда блокирует удаление ассета в этом сеансе** — временные пробы в отдельном headless-процессе; `delete_asset` проверять `os.path.exists`; переименование = удалить+создать в свежем процессе.
- **In-memory ≠ диск** — верификация через свежий процесс/перезагрузку; `get_referencers` сразу после операции устаревший.
- **Движок чинит usage-флаги материала в памяти** — чтение свойства не доказательство; доказательство — лог свежего процесса после пересохранения.
- **Треугольники меша** — тег реестра `AssetData.get_tag_value("Triangles")` (у StaticMeshEditorSubsystem метода нет).
- **Headless trace/sweep без PIE невалиден** (Chaos не инициализирован); коллизию — только живой PIE; `set_collision_enabled` не сериализуется — только `set_collision_profile_name`.
- **`connect_material_expressions` сокращает имена пинов** — проверять bool; MI: родителя задавать `set_material_instance_parent` после create_asset; `set_material_instance_scalar_parameter_value` всегда возвращает False — проверять обратным чтением.
- **Спавн с transient=True всё равно пачкает карту** (dirty), содержимое диска не меняется — проверять md5.
- **Размер текстуры в коммандлете** — тег `Dimensions` реестра; `blueprint_get_size_x()` врёт избирательно.
- **`SetBrushFromTexture` не сбрасывает тинт кисти**; стиль главного меню живёт на КОНТРОЛЛЕРЕ (`StartScreenStyle`), WBP_StartScreen генерится коммандлетом.
- **Сокеты класть на СКЕЛЕТ, не на меш** (модульная броня подменяет меши); сокет нельзя звать именем кости. Скелет гуманоида: 22 кости, справа имена сдвинуты (`R_Arm`=плечо, `Pelvis_009_R_002`=локоть) — зеркалить по именам нельзя.
- **Кириллица**: в ASCII-логе UE — мохибейк (проверять обратным чтением); в `.ps1` — ломает парсер (писать латиницей); буквы в окно игры ломает русская раскладка (WM_INPUTLANGCHANGEREQUEST + проверка потока окна).
- **GUI-автоматизация:** перед каждым вводом `GetForegroundWindow` должен быть UnrealEditor, иначе стоп (за компьютером может быть живой Ринат).
- **Дробные в Android-настройках читает C#-сборщик по локали** — писать целыми; движковые CVar (`r.MobileContentScaleFactor`) не подвержены. CVar профилей устройств — в САМЫЙ частный профиль цепочки (для realme — `Android_High`/`Android_Unknown_Vulkan`), проверять живым журналом.
- **У cpp-dev файл-замок `.build-lock` в корне** — смотреть перед занятием проекта; чужие незакоммиченные правки в дереве не трогать и не коммитить (только свои точные пути).
- **`cmd.exe /c` из Git Bash не работает** (MSYS превращает /c в C:/) — движок звать напрямую с MSYS_NO_PATHCONV=1.
- **`EditorAssetLibrary.rename_asset` НЕ оставляет редиректор** — ссылки ассетов чинит сам, а строковые пути из C++ умирают молча (таблицу генератора после переименования окна обыска чинил cpp, 4dfa224). Создать редиректор из питона нечем — перед переименованием грепать путь по Source/.
